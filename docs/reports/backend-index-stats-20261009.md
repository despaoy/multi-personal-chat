# 索引状态实际类型（2026-10-09）

## 修改

VectorDatabase.get_stats 曾直接用包装层返回的 FAISS 基类对象判断 Flat/IVF/HNSW，可能把正常索引报告为 unknown。使用 faiss.downcast_index 获取原生具体类型，同时合并重复的非空和类型判断。

类型信息来自实际已加载索引，不从配置猜测。因此加载既有快照时，即便构造参数是默认 auto，也能报告快照的真实类型。

## 验证

服务器 3 项定向测试通过，0.99 秒。使用真实 FAISS 创建 Flat、IVF、HNSW 空索引，保存完整快照并重载，经 get_vector_stats API 验证类型和三类数量统计。没有调用模型，也没有运行全量回归。

本阶段仅修正状态报告，不修改索引内容、配置或搜索算法；未声称覆盖大规模非空索引性能。部署、增量规范及同版本同步记录位于服务器本阶段备份目录。
