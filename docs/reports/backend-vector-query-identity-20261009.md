# 查询缓存绑定原始模型输入（2026-10-09）

缓存键原先将 query 转小写并合并空白，实际嵌入仍接收原文。两个不同模型输入可能共用缓存而跳过第二次编码。删除仅用于缓存的 _normalize_query，用 JSON 序列化原始查询、top_k、threshold 和有效 filters，保持字段边界及稳定字典顺序。无语义改写或额外兼容分支，生产代码净减少六行。

服务器三项定向测试通过（1.61 秒）：大小写与换行不同的输入分别绑定显式不同向量，真实 FAISS 检索分别命中对应文档，重复查询正确复用各自缓存；相同筛选条件仅字段顺序不同仍复用一次编码。四条警告来自已有 jieba/pkg_resources 依赖。

没有全量回归、真实或付费模型调用。替身用于证明缓存不会擅自合并不同模型输入，不代表真实模型一定将每种大小写/空白差异编码为不同语义。运行中旧缓存随后端重启清空，不修改磁盘索引格式。
