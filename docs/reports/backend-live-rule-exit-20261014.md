# 退出在线关键词适配器分发，保留历史评测（2026-10-14）

## 依据与实际状态

真实调用链为管理页 → 路由配置/兼容性 API → 生成入口按关键词切适配器 → 默认/激活适配器回退。规则模块还被离线 S1 评测和历史回归使用，不能仅删除类留下管理页或假称新语义路由。服务器只读确认旧开关为 false、激活适配器为 0；当前工作没有先改变生产模型或用户数据。

原先包含删除规则模块、离线评测脚本和 Hook 的较大方案，被自动审批因历史流程和调用方风险拒绝，未执行。采用真正较小的替代方案：不删除任何文件，不修改离线规则模块和评测脚本，原字节校验值保留；只退出在线分发、阻止重新启用并简化当前管理页。没有拆分原删除操作绕过拒绝。

## 在线行为与界面

生成入口删除关键词路由及其吞错/默认适配器处理；请求中的角色名不再自动选择 LoRA，也不会调用旧意图规则或未训练分类器。请求明确指定的角色/适配器和现有激活设置仍生效；不支持的组合继续明确拒绝。知识检索意图仍由当前 DeepSeek 语义链路处理，分类器训练接口保留。

旧配置读取/关闭接口保留并标记 routingAvailable=false，旧配置只作历史资料；重新启用、rule 或未接入的 intent 模式在写入前返回 409。现有配置的并发读改写仍保留；测试改为两个受支持的关闭/手动配置更新，仍断言所有字段都写入，不放宽序列化检查。历史路由日志接口和离线实验功能保留，但在线生成不向它们加入新的规则决策。

管理页去掉在线开关、模式、关键词配置、保存控件及路由日志展示，导航改为“适配器检查”。保留管理员访问、兼容性状态、刷新和主动检查。现有 Hook 文件保留，功能边界缩为适配器数据；请求失败显示错误与重试，不将故障改为空数组，也不填充猜测的结果。检查成功后刷新失败明确说明检查已完成但列表未刷新，不给成功提示。

## 兼容性故障与保存

适配器没有检查记录是正常未检查，没有适配器是正常空列表。已有检查记录的 JSON/结构错误及数据库/目录故障返回 503，不再补空 checks/warnings/errors 伪装成功。完成检查后必须确认实际 INSERT 影响一行，才能返回成功；兼容或不兼容报告都保存真实结果。保存异常或未确认返回 adapter_compatibility_record，并说明 checkCompleted=true、recordSaved=null，不声称回滚或保存成功。没有引入默认适配器、旧缓存或 mock 降级。

保留原接口地址及活跃客户端类型，不删除历史配置、检查记录、研究资料、冻结结果或评测来源。未重写兼容性检查算法，没有改变角色提示词、模型选择、生产记忆与索引。
