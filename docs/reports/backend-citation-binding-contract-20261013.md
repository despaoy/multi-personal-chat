# 引用绑定不再静默跳过损坏数据（2026-10-13）

EvidencePacketBuilder 原先把标识冲突、标识缺失及引用对应文档缺失转换为警告或静默跳过，可使部分损坏的检索结果看起来正常。现冲突/缺失标识明确抛 ValueError，对应文档按标识直接读取，缺失抛 KeyError。故障传播到既有接口错误出口，停止模型生成。

CitationValidator.bind 直接读取证据包已确定的 key 和 document_id；元数据缺失不再跳过，文档标识不再重复从 source_id 或空字符串猜测。正常预算选择和上游实际使用的两类引用标识仍保留，不增加包装层或重复校验。

服务器 7 项定向引用/预算测试通过（0.33 秒），另 2 项真实服务编排的正常非流式/流式回答测试通过（0.36 秒）。覆盖三类构建故障不调用模型、两类绑定元数据损坏、来源字段权威回填、正常预算选择，以及正常引用绑定和历史缓存隔离。使用完整合成资料，未调用付费模型，未运行全量回归。语法和差异检查通过，无新增静态问题。生产代码净减少 8 行。

本阶段只完成引用构建和绑定中的已确认静默跳过问题，其他证据处理分支仍需继续审查。
