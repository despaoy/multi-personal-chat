## 修改

- 作品问答从本次来源目录中的完整声明片段建立回答证据；索引只保留召回排序、原生 parent ID 与索引版本。回答不再使用旧索引正文、摘要、标题或未核实的叙事标签。引用类型为原作片段，标题取实际文件名，范围来自同一片段快照。
- 可用证据数量来自当前来源集合，不受旧索引文本的引用预算影响。缺少来源的显式 `no_visible_source` 保持正常证据不足；缺失绑定、重复 parent、跨域绑定等协议错误明确失败。
- 实际生成时，当前完整来源集合超过原有回答证据预算就报错，不截断或只回答其中一部分。检索已判为低置信度时正常弃答，不为不会生成的正文消耗预算。
- 两轮检索保留完整的 sources/unavailable 集合；相同记录去重，来源快照或可用状态冲突报错。无来源目录的文档检索保留原有契约。
- 来源目录解析归一到共享函数，继续使用既有生成前后及缓存读取时的文件校验。提示词版本更新为 `grounded-answer-v3`。没有增加分类规则、模型调用、依赖或配置项。
