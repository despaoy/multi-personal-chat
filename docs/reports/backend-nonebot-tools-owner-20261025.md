## 实现

工具调用使用现有Pydantic严格解析tool与显式args对象；不从正文猜JSON片段，不删除围栏、补空参数或忽略额外字段。未知工具和参数签名错误在执行前失败；合法查询无匹配文件仍是正常业务结果，目录不可用与平台发送错误继续报错。错误在消息入口清楚报告，原始代码、参数、服务错误正文不进入用户错误提示或业务日志。

独立脚本的进程所有权收敛到现有services/tool_execution.py，保留独立脚本、相邻模块导入和当前Python依赖的语义，没有把它替换为受限函数执行。使用当前解释器、最小环境和UTF-8；不继承后端密钥。异步读取输出，每条流上限64000字节，超限报错而非截断成功；默认30秒期限；POSIX超时、取消及结束均清理进程组，读取并关闭剩余管道。Windows仅实现直接子进程清理，本阶段未进行Windows进程树验收。原有HTTP受限函数工具的校验、资源限制和业务函数语法树不变，仅共用相同环境构建；独立脚本执行不是操作系统安全沙箱。

生成代码使用唯一工作子目录、明确UTF-8保存，文件须位于所属工作目录；运行目录加入Git忽略。只有零退出才报告运行成功；保存后执行失败明确说明文件已经保存。状态采样移到线程执行。删除无调用方get_tools包装、重复代码分支和日志，生产源码净变化-8行。
