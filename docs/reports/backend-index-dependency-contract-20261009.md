# 索引依赖失败契约（2026-10-09）

## 问题与修改

`_ensure_vector_index` 在 VECTOR_DB_AVAILABLE=False 时曾设置本地 built/revision 并返回 True。依赖缺失因此被表示为重建成功，允许上层继续检索。

删除这条分支和重复的可用性标志导入，直接依赖实际向量模块导入；ImportError 进入既有失败出口，返回 False，上层搜索返回 503。索引版本读取和重建失败日志仅记录异常类型，不输出可能含私有内容的底层错误文本。生产代码净减少 7 行。

## 验证

服务器 3 项定向测试通过（3.55 秒）：实际统一重建入口在依赖导入失败、版本读取失败时经搜索接口返回 503；异常类型可查，私有错误文本不出现在日志或响应；依赖失败不设置本地完成状态。另保留既有正常空结果测试，确认不触发备用检索。

测试明确注入依赖和数据库读取故障，无真实模型调用；没有重跑全量回归。本阶段未更改其他模块的可用性标志，也不声称覆盖全部依赖或所有日志。

部署健康、语法和增量规范、同版本同步记录位于服务器本阶段备份目录。不提交私有原文、配置或运行数据。
