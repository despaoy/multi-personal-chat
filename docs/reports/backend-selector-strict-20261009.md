# 证据选择审核：第十阶段（2026-10-09）

基线 ee0444cd459b1efd7de9d15821d4a8720792d87f。服务器先修改和验证，部署后同步本地、GitHub。

## 问题与修改

`character/evidence_selector.py` 将超时、提供商异常、非法输出、输入超预算和候选 ID 错误转换为空集合，角色服务仍继续编译。配置入口还吞掉非法超时并使用默认值，构造器将超过 120 秒的值截断，选择器把超过 24 条的候选静默截掉。

现在必要审核失败直接传播，沿已有 API 边界返回脱敏 503。超时保留取消与资源释放行为；缺少分类、重复 ID、伪造 ID、未知标签和改写证据继续拒绝。输入超预算和候选超量明确报错，不能删掉必要内容换取成功。超时必须有限且处于 (0, 120] 秒；显式输出上限必须是非负整数。

正常无候选仍跳过模型审核；模型完整分类后把所有候选判为无关仍是合法的成功空结果。选中的内容保持原对象和完整证据，不由审核模型重写。明确配置的输出数量上限继续有效，关闭审核也保持明确的配置路径。

删除选择结果和准备结果中的回退原因字段，同步服务日志、四个原生链路探针与离线评测入口。评测遇到审核故障直接失败，不将空集合计为正常审核结果。历史评测数据未改动。

选择器净减少 24 行，服务减少 2 行，四个探针和评测入口合计减少 5 行；核心修改合计净减少 31 行，没有新增依赖或通用错误层。
