# 原作证据审核故障明确传播（2026-10-14）

## 实际问题与修改

聊天的公共证据入口在角色原作分支直接调用 review_curated_bundle。该函数原先捕获容量不足、超时、源文件错误、解析错误和任意提供商异常，返回 status=unavailable 的收据；调用方可能继续使用私人上下文或生成“证据不足”式回复，把系统故障当成普通业务缺口。

删除该函数的异常吞掉和失败状态初始化，只在完整审核成功或正常没有可靠候选时返回。容量、提供商、格式、原文版本变化和读取错误保留原始异常向上传播，聊天入口现有统一处理返回 HTTP 503，停止回答。失败时不返回部分审核收据或把未完成审核当作完成。生产代码净减少 10 行，没有新增错误框架、配置或降级。

合法的 no_candidates、完整审核后 not_supported 保持正常业务语义；不把无支持编成负向事实。一次有效审核之后的来源失效仍使用既有精确来源/依赖剔除机制，保留独立证据和明确的失效状态，不在本次改动中改变撤销、授权或历史数据语义。

## 定向验证

服务器 15 项直接相关测试全部通过（1.22 秒），28 项无关测试未运行。覆盖有效人物自述、完整原文及否定/例外传入生成、审核后来源失效、完整不支持结论、取消传播、混合资料权限，以及完整输入和目录容量不足。

新增六组实际聊天入口故障控制：提供商错误、超时、缺失审核任务、输入容量不足、审核期间原文修改及删除。均要求 HTTP 503、原始异常类型/原因保留、回答调用为零；容量不足发生在审核调用前。错误输入的完整原文与已绑定任务均已提供，失败不是由于省略测试前提。

旧错误测试改为要求异常和输入不变，不能继续把失败收据当作可用结果；保留正常成功与无支持断言。语法、增量静态和差异检查通过，无新增静态问题。未重复全量回归，付费模型调用 0，未修改生产原文、索引或用户数据。

本次覆盖原作审核分支及统一 API 失败阻断，不等于通用知识库来源审核、事实覆盖审核或独立检索分支已全部移除故障降级；这些仍需继续按实际链路清理。模型审核质量没有在本阶段重新做付费评测。整体优化目标继续。
