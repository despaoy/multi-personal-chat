# 纠正检索合并拒绝同 ID 证据冲突（2026-10-09）

结构化纠正检索原来只用 seen_ids 去重，后轮同 ID 内容变化被丢弃，却沿用后轮置信度，可能让旧正文与新结论组合。现在用按 ID 保存的文档表替代列表加集合，重复文档须在回答层使用的正文、摘要、标题、来源、域、版本、文档类型、元数据与适用范围字段上保持一致；冲突明确抛出 ValueError，不返回混合证据。必需文档 ID 直接读取。

相同证据仅分数变化仍正常去重，保持既有排名与引用顺序规则，不更改重试后的成功阈值。对两个输入不写入排名字段。

服务器先有 14 项定向测试通过（1.62 秒），对照回答层后补充文档类型字段，仅新增 1 项检查通过（1.51 秒），合计 15 项。覆盖 11 种权威内容字段冲突、正常同 ID 不同分数、三个既有重试结果。四条警告来自既有 jieba。无全量回归、付费模型。本检查针对重复文档冲突，不宣称所有不同文档或证据包来自同一全局索引快照。
