# 2026-10-19 搜索结果身份与失败语义

基线：`6d1bb665257ba552d828f59e854f8ccf9a8d4684`。

## 实际问题

知识库索引将片段身份保存在 `id`，将数字文档编号保存在 `document_id`。搜索接口误把前者输出为 `documentId`，例如返回 `doc_1_chunk_0`，与客户端数字类型及文档读取接口不一致。转换过程还把必需标题、内容、片段序号或分数的缺失替换为空值或零值，可能让不完整结果表现为成功。

响应辅助函数另行接收检索模式，维护四种模式的映射，但现用搜索链路只返回有证据结果或正常空结果。当前没有关键词回退入口，客户端仍声明的 `hybrid`、`keyword` 及“故障时降级”注释已过期。

## 修改

- `documentId` 使用真实 `document_id`。内部片段 `id` 继续承担检索与引用身份，未被全局改名或替换。
- 直接使用检索结果约定的标题、片段序号、完整内容及归一化分数。缺少必需字段由已有错误边界报告 503，移除空文本、零值和替代分数，未增加校验分支。
- 根据最终结果是否为空推导 `evidence` / `empty`，删除多余模式参数、类型及映射。继续返回当前客户端实际使用的 `searchType` 字段，其有效值为 `rag_pipeline` / `empty`。
- 客户端模式类型同步收敛到实际返回值，修正降级注释。两个生产文件合计净减少 **15 行**，没有新增配置、模块、重试或保障分支。
