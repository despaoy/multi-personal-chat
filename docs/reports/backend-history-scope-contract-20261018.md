# 记忆范围与历史消息契约整理

日期：2026-10-18。基线：`41b6a96`。

## 实际修改

记忆模型提出无效范围或缺少用户授权的跨会话、跨角色范围时，原实现会悄悄保存成当前会话范围。现在复用现有字符串校验和统一错误处理，明确返回 `scope_level` 协议错误，不改变要求来换取成功。合法范围保持不变，省略可选范围仍按已声明的当前会话契约处理。

没有新增范围关键词、正则、策略层或错误包装。现有授权检查保持原样，生产代码净增加 2 行。批量提议中任一范围错误都会在写入前失败，不留下部分记忆；发言来源仍按原流程记录。

上下文与记忆存储测试补齐必需的记录类型。合法历史与非法角色分别验证；系统、工具角色作为普通历史输入时明确失败，不再声称会自动过滤。省略句的提议直接引用当前原话，时间字段使用已声明的顶层格式。

历史预算测试使用实际 token 计数推导边界，并先证明测试消息确实超出指定窗口。已选记忆超限的旧“丢弃后成功”预期改为明确错误，后续策略不得继续执行。只测试记忆选择的组件明确关闭不属于该测试的来源检索功能；存储状态接口提供完整的私人记忆规划控制，继续要求不进入公共检索或回答生成。
