# 纠正检索参数拒绝隐式改值（2026-10-09）

CorrectiveRAG 构造时原先用 max(0, int(max_retries))，负数会关闭重试，小数被截断，布尔值和字符串被解释成次数；threshold 未验证，非有限值可干扰后续弃答判断。现在重试次数必须为非负整数，阈值复用现有 parse_unit_interval 验证有限的 0 到 1 值，非法设置在检索前明确抛出带参数名的 ValueError。不新增解析框架、配置项或备用策略。

服务器 16 项定向测试通过（3.56 秒）：五种非法次数、七种非法阈值均在调用检索前失败，两个合法阈值端点原样传入，既有零次重试与重试耗尽弃答行为保持。四条警告来自既有 jieba。生产默认阈值 0.3 和重试次数 1 不变；实验现有合法阈值/整数次数仍有效。无全量回归、无付费模型。
