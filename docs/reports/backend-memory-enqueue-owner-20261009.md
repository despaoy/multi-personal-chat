# 后台入队拒绝逻辑单一归属（2026-10-09）

schedule 已按缓冲、排队、处理中总任务数限制容量，asyncio.Queue 使用相同容量但存放非空批次。因此两个同步入队入口在合法状态下不可能再次 QueueFull：批次数不超过任务数，缓冲转排队也不增加总任务数。删除 _enqueue 的布尔成功协议和调用方两套 queue_full 跳过分支；它只负责启动 worker、实际入队和记录排队任务数。若内部入队仍发生异常，则明确抛出，不伪装成普通容量跳过。

保留入口 capacity 拒绝和既有顺序/回执语义，不增加并发框架。生产代码净减少 13 行。

服务器五项定向测试通过（0.62 秒）：同 scope idle/hot 顺序与释放容量；两任务合成一批仍占用两任务容量，满额时第三任务拒绝且已接受批次完整执行；注入内部 QueueFull 时异常传播而不是计为 skipped；既有等待超时和关停回执验证通过。没有全量回归、真实或付费模型调用；调度隔离测试使用明确处理替身，超时测试运行既有提案解析与删除流程。
