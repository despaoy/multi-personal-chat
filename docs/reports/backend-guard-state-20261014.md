# 删除不可达输出降级状态，评测记录明确失败（2026-10-14）

## 调用链与修改依据

沿共享生成 → 有界输出修正 → 引用绑定/补标 → API 结果分类 → 新评测记录检查，确认生产没有任何位置赋值 GenerationResult.guard_fallback。一次修正仍未满足输出约束时已经抛出 ReplyValidationError；该字段仅保留空默认值，却继续被组合任务、引用和结果分类用作条件，测试甚至手工构造不存在的降级回复。

删除字段及四处不可达条件，保留原有一次修正上限、轻量/显式离线严格模式和实际异常传播。未通过校验不会返回生成结果，所以无需再在引用绑定中识别一个虚构的成功降级状态。四份生产模块净减少 4 行，不更改输出校验规则、主答模型、权限、证据准入或语义任务规划。

新评测/探针不再写 guard_fallback 列。共享上下文评测识别实际 ReplyValidationError，记录 reply_validation_failed、剩余闭合违规 ID 和已发生的模型尝试；最终 reply 仍为空，状态为 error。两处新报告汇总改为实际输出校验失败数量。没有输出固定替代回复、伪造通过分数或把失败当生成成功。

历史评测文件保留。只读审计允许新记录缺少退休字段，已有旧字段仍用于拒绝历史降级结果；旧修正回放仍可按原字段选择历史案例，当前输出显示实际修正后违规。未把旧降级资料恢复为当前运行状态，没有更改历史模型响应或重标为新调用。
