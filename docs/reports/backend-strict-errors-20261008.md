- 检索及对象绑定审核异常返回 HTTP 503，保留异常链；不会继续调用回答模型，不把故障写成证据不足。

- 模型管理器异常不再触发提供商自动切换；保留现有 HTTP 500 错误出口，日志仅记录错误类型，避免打印模型异常原文。
