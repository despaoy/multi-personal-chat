# 保留记忆授权针对的事实

基线：`53db174160766252819651e69c58fe706a4fbaf0`。

在完整隔离原文中明确要求“姓名让所有角色记住，专业只在当前会话使用”。修复前的全新 DeepSeek 请求确认：范围审查引用了专业的限制，返回全局不授权；主写入只能选择当前会话，最终两项都保存为当前会话，任务却正常返回已保存。第二个预定用例未执行，保留首个失败记录，没有扩大测试或更改原文。

原因是范围结果只保留范围集合，丢弃了授权针对的事实引用，且布尔语义没有区分并列事实。现在保留已验证、来自完整当前原文的授权引用；允许范围从这些授权派生，不再独立保存第二份范围状态。审查明确逐项事实判断，某项限制不能覆盖其他事实的明确授权；写入请求接收对应授权引用，逐条应用各自范围。

没有新增关键词、分类器、检查分支、外部依赖或模型调用。普通会话仍不额外调用范围审查，宽范围任务仍为一次审查加一次主写入。生产代码净增加 10 行，用于事实引用传递和派生范围。原范围越权错误、原文绑定、协议和预算校验保持原实现；其余生产顶层定义经 AST 对比一致。
