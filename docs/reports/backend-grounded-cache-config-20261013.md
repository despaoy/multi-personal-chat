# 回答缓存配置不再自动修正（2026-10-13）

AnswerCache 原先用 max 修正负 TTL 和非正容量，int 转换还会截断小数容量，无穷 TTL 可使缓存无限保留。现 TTL 必须是有限非负数且不能是布尔值，max_entries 必须为正整数；不合法配置明确报错。TTL=0 仍显式关闭缓存，不新增策略层或自动降级。生产净增加 5 行。

服务器 13 项定向测试通过（0.37 秒）：五类非法 TTL、六类非法容量，以及通过完整知识回答编排验证禁用缓存和正 TTL 命中/过期重新生成。时间由测试控制，不实际等待，无付费模型调用，无全量回归。语法和差异检查通过，无新增静态问题。

本阶段只处理配置约定，淘汰算法、其文档声称的 LRU 与实际按写入时间淘汰是否一致，以及其他缓存失效边界仍需继续审查。
