## 问题与修改

原解析器搜索任意说明文字中的首个 JSON，并忽略其后内容；候选列表先截到八条、有效结果再截到四条。畸形非对象候选也被当作正常拒绝而略过，可能将不完整结果视为成功或无变化。

- 对完整响应执行单个 JSON 解析；明确保留已有裸数组和完整 JSON 代码块支持，不再从前后说明、拼接结果或缺失闭合的代码块中截取部分数据。
- 非标准 NaN/Infinity 和重复字段明确失败；解析错误不回显模型原文。
- memories 必须是对象数组，数量不得超过提示中约定的四条。超量或混合非对象候选在验证/写入之前整体失败，删除两层静默截断和内部重复类型检查。
- 正常空数组仍是无变化，证据不支持、无授权等业务拒绝规则保留。本阶段未扩大候选必填字段校验，不声称所有候选语义错误已经可检测。
