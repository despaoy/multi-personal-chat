# 角色查询向量缓存容量与并发（2026-10-09）

LocalMeanPoolingEmbeddingProvider 的进程级实例原先使用无上限字典保存所有查询向量，缓存读写又在已有运行锁之外，并发相同请求可能重复编码。改为 OrderedDict，保留最近使用的 256 条，在已有 RLock 内完成查询、编码和缓存写入，不添加配置或额外锁。

缓存仅属于该固定模型实例，实例销毁即失效；缓存是同一模型对相同输入的向量，不是业务答案，不引入按时间过期。超过容量淘汰最久未使用条目，后续重新编码；失败不缓存、不使用其他查询结果代替。继续向调用方返回数组副本。

服务器三项定向测试通过（0.42 秒）：257 条查询及再次访问验证淘汰与近期命中，返回副本隔离；编码异常原样传播且下一次重新编码；八个并发相同请求仅编码一次。使用明确编码替身，不调用付费模型、不重测全量回归，也不声称重新验证嵌入质量。固定 256 是容量上限，不是延迟性能基准结论。
