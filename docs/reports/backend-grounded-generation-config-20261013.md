# 生成超时与回答长度配置明确约定（2026-10-13）

GroundedAnswerService 原先只转换 generation_timeout 和 answer_max_chars，非有限超时可能使保护失效，负长度则隐式禁用正文限制。现超时必须为有限正数且不能是布尔值；回答长度必须为非负整数，不接受布尔、字符串和小数的隐式转换。显式 0 保持不限长度语义。生产净增加 5 行。

服务器 13 项定向测试通过（0.39 秒）：十类错误配置、流式与非流式真实等待超时后取消模型工作、显式不限长度的正常完整回答。完整合成资料，未调用付费模型，未运行全量回归。语法及差异检查通过，无新增静态问题。

只验证生成参数的这两个约定，整体后端优化目标仍未完成。
