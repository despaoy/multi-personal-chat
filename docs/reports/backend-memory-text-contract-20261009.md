# 记忆提案文本字段契约（2026-10-09）

## 修改

模型 kind、value、content、target_memory_id、target_memory_key 曾通过 str(... or "") 强制转换，结构或数字错误可能被变成字符串后当作正常无结果处理。

增加一个共用的文本读取函数，六个文本字段（含 evidence）统一拒绝非字符串，并报告字段名，不输出字段值。原本可省略的字段仍可省略，使用已有空字符串语义；evidence 仍必须非空。原有规范化、归属、证据支持和目标授权规则不变。

## 验证

39 项定向测试最终通过：六字段的 null、数字、布尔、列表、对象错误，省略可选字段的正常 ADD，以及直接相关的既有记忆解析测试。首轮 38 passed、1 failed；新增测试误写了既有标准化文本，核对未修改的 canonical 规则后改为“用户说喜欢红茶”，仅重跑该项，1 passed（0.34 秒），没有修改业务规则迁就测试。
