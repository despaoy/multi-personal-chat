## 修改和影响

- 删除没有其他业务调用方的 `DomainProfile`、默认游戏词表、`QueryExpander`、隐式开关和过滤推断分支。每个原问题或已验证视图只进行一次混合检索。

- 过滤完全来自调用方显式条件；`region` 与知识库、类别等一起交给真实索引匹配。缓存身份继续包含完整问题、实际重排模式、过滤条件和索引版本。不可序列化的过滤条件明确报错，不再通过字符串转换生成缓存键。
- 生产代码净减少 281 行。清理只验证旧词表扩写或推断行为的过期用例，保留完整原文解析、显式访问范围及失败校验；新用例直接覆盖实际检索行为。去掉测试中失效的规则关闭开关。

旧的通用游戏别名替换和隐式地区/类别缩小范围不再执行；语义任务规划、已验证的指代对象搜索、向量/BM25、可选重排和明确的无匹配弃答保持原有职责。没有增加模型调用、分类器、依赖声明或配置项；独立纠正检索接口及其既有调用方不在本次修改范围内。
