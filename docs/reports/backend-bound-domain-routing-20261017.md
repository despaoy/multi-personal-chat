# 已确认对象的检索域与查询分析复用

## 问题与修改

语义流程已经确认角色对象后，旧入口仍按问法关键词再次选择域，单字别名可能因此进入通用知识库。显式指定已有域也会被问法门控忽略；未知域则可能转而扫描其他域。

本阶段让主生成入口直接使用已有对象绑定确定的来源域。独立来源检索共用这一入口；正式业务全名继续使用通用知识库，未解析任务不会被当作已确认的对象。指定未知域立即报错，所需角色来源不可用、结果协议错误和正常无证据分别保留各自结果，不切换来源掩盖失败。

同一次字面别名扫描的跨度同时用于实体提取和文本归一，运行时把这份分析传入检索服务，消除重复扫描。对象范围使用独立副本，不改写共享分析；多域命中时保留原查询，不再按第一个域静默归一。

真实语义抽查暴露人物姓名边界问题后，补充了通用的姓名、身份描述和主语动作区分说明，以及完整名称声明优先的定义。没有程序裁剪名称、增加关键词分类或替换模型。原始问题完整保留。生产代码新增 93 行、删除 106 行，净减少 13 行。

## 验证

- 137 个直接相关的独立用例通过，无失败或跳过。只复测失败和新增影响项，没有重复运行全部回归。覆盖显式域、单字别名、历史指代、正式业务全名、混合任务、空索引、向量故障和来源协议失败。
- 对照保留其余 242 条原有断言。一项旧检索提示断言迁移到已负责生成提示的绑定视图入口，一项断言更新为所需来源不可用的实际错误契约；没有通过删掉有效检查让结果变绿。
- 真实 `deepseek-flash` 语义审核共四次，回答生成零次。前两次为任务规划与对象绑定，其中对象绑定失败记录保留；修改语义定义后，原问题复查通过，另一次正式业务全名对照也通过。成功规划仅在确认输入完全相同后复用，明确记录为旧真实结果，不计为新审核。
- 真实向量模型配合完整虚构证据验证角色来源、完整原文、单次别名扫描及不进入通用来源。业务依赖使用明确的测试控制输入，不声称为新的模型判断。
- 现有索引 1,098 条文本的新旧归一结果一致，索引资产哈希未变，无需重建。
- 静态检查无新增问题，差异格式检查通过。服务器已部署；复核源码哈希一致，后端就绪与前端登录均为 200，配置和其他服务未变。
