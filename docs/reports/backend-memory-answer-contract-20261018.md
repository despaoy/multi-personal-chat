# 记忆回答与来源失败契约收敛

日期：2026-10-18。基线：`4debdd1`。

来源读取适配器删除了对缺失接口异常的重复包装，与其他必需数据库接口统一：接口缺失直接失败，不能成为空读取。成功调用的参数与返回路径保持完全一致。

证据入口明确检查引文对应文档是否存在，缺失文档与冲突编号均报错，不再由旧测试要求返回空证据和警告。生产代码合计净减少 1 行，没有新增语义关键词、正则、策略层或错误包装。

相关测试补齐了当前记忆回答的私人、公共和当前输入依赖控制，并在实际检索入口检查是否发生外部读取。已知字段仍要求零回答模型调用，缺失私人字段与私人、公共混合请求继续走对应路径；最近历史仍优先于已保存的旧资料。

来源删除测试以实际撤销水位构造时间：水位之前的请求为 `stale`，之后重用已撤销来源编号为 `revoked`，两者都不能恢复正文或摘要。测试不再依赖固定日历日期与机器当前时间的偶然关系。

118 个不同的定向用例通过；时间前提进一步整理后，只重测相应一项。静态检查、差异检查通过，来源读取成功调用的 AST 保持一致。本阶段没有真实模型 API 请求，单元测试的 HTTP 传输隔离保持启用；这些结果不作为模型理解质量证据。

服务器后端更新后就绪 200，前端登录 200，匿名受保护接口 401，配置未变。9 条旧失败记录已核对，剩余 29 条待审；整体优化与最终整体验收尚未完成。
