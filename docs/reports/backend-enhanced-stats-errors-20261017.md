# 管理状态读取故障明确返回错误

隔离复现确认：启用 vLLM 后，客户端初始化或统计读取异常被共享辅助函数转换为 `None`，综合状态及统计接口仍返回成功，并把故障显示为未启用。

修复保留未启用时不创建客户端的行为；启用后的初始化及统计错误统一返回 503，异常链保留真实原因。日志记录异常类型，响应说明失败组件及检查配置、服务状态的恢复方向，避免暴露私有连接信息。请求取消继续传播。正常返回的数据及健康实例为零的诊断结果保持原样，不把实际不健康数据当作解析故障。

15 项定向测试一次通过，覆盖两个失败阶段的三个实际管理 API、原因保留与日志、取消、未启用、有效健康统计和三个关联旧契约。未重复全量测试，未调用真实模型。AST 核对确认只修改共享读取函数，所有接口字段、鉴权依赖及其他端点代码未变；静态检查无新增问题。

服务器先修改、测试并部署，后端就绪和前端登录页均为 200，匿名访问保护接口为 401，安全响应头正常。当前模型配置、其他服务和运行配置未改变，随后同步本地和 GitHub。

本阶段处理统计链路错误，不代表所有模块的错误处理已完成。生命周期关闭失败的汇总及异步 Redis 清理仍需按真实调用链继续检查，总体优化目标保持进行中。
