# 回答缓存按最近使用淘汰（2026-10-13）

AnswerCache 文档约定 LRU，旧实现却按写入时间扫描最老条目，读取不更新顺序。改用标准库 OrderedDict，读取和写入移至末尾，超容量直接删除首项；不改写 stored_at，因此读取不会续期。写入先完成结果复制再替换缓存项，避免复制失败前先删除旧值或淘汰其他答案；异常仍传播。无新增依赖或策略层，生产净增加 1 行。

服务器 4 项定向测试通过（0.35 秒）：读取/替换两种最近使用顺序、有限容量、TTL不续期、返回数据隔离，以及替换/新增复制失败均保留原答案。完整合成答案，可控时钟和失败注入，无付费模型、无全量回归。语法和差异检查通过，无新增静态问题。

本阶段覆盖淘汰及缓存写入原子性，不声称全部缓存身份与服务配置变化的失效策略已审查完毕。
