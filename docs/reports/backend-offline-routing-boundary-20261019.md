# 历史路由配置与离线预测分开负责

基线：`7b930906e4a0482b4df5ac0dab45a35549f1c8a9`。

从应用依赖、配置保存、路由调用方及研究脚本复查发现：在线自动路由已经停用，历史配置写入后仍构造离线路由器；意图依赖失败会继续按关键词选择，缺少或非法适配器也会被替换成虚构名称或默认项。

受控 SQLite 复现确认：配置已写入成功后，未使用的离线工厂异常让 API 返回 500。现删除此调用，配置保存只负责本应用数据库的读改写。正式角色选择、配置接口、兼容性检查、日志读取及在线自动路由停用状态保留。

离线实验中，分类器导入和预测错误直接传播；不存在的角色适配器、非法或空名称明确失败。意图结果统一解析为完整三项，不再补出缺失字段。现有关键词、显式手动选择及历史记录字段保留原定义，没有增加规则或启用新分类器。

同时复现了分数失真：旧路由读取 `needs_rag` 的原因文本接口，把实际 0.63 概率变成 1.0，越过配置的 0.8 阈值。新增很小的数值预测入口，仍使用原模型加载和预测实现，返回原始分数及知识目标；路由直接读取该结果。原带原因的 `needs_rag` 接口及其实现不变，避免继续猜测字段含义。生产代码合计净减少 20 行，没有新增保障分支或依赖。

## 验证

- 五组直接相关测试选择共 38 项首次全部通过、零跳过，包含八个新增行为用例。覆盖失败传播、完整数值协议、分数不被提升、两个应用分别保存配置、身份与权限边界，以及在线规则继续停用。未运行全量回归。
- 180 条有效输入的原决策逐项一致：80 条手动状态、80 条规则研究状态及 20 条具备完整预计算意图的状态。剩余 60 条缺少预计算意图，真正跑意图实验需要已训练分类器；没有补标签、猜测结果或据此宣称当前分类器准确率。
- 原先五种被静默替代的错误均明确抛出。受控模型结果的 0.63 分数原样传递；阈值 0.5 时使用该分数，阈值 0.8 时不被伪造的 1.0 越过。旧原因接口保留原三项结果。
- 离线工厂被设置为失败时，历史配置仍真实保存成功，工厂调用次数为零。相关 HTTP 测试保留全部原数据库、认证和兼容性断言。
- 原路由单测中混用原因字符串和数值置信度的夹具已改为完整数值结果，并检查原值 0.93；错误使用原因字符串的输入改为明确拒绝。原始研究数据和历史结果没有修改。
- 静态检查、仓库完整性与差异检查通过。测试使用受控预测、合成身份和隔离 SQLite，没有训练模型或调用 DeepSeek，也不作为新模型质量评测。
- 服务器启用后端后就绪 200、前端登录 200、未登录受保护接口 401 并保留 `nosniff`。配置及其他服务保持不变。
