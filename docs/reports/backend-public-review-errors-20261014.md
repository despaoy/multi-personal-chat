# 通用来源与事实审核错误明确传播（2026-10-14）

## 实际问题与修改

真实聊天入口调用 review_public_candidates。该函数原先把对象解析、身份关系、来源审核的容量、超时、格式及提供商故障转换为 review_status=unavailable，过滤候选后继续运行。子链路 bounded_review、resolve_fact_scope、review_fact_evidence 也会吞掉错误，再返回不可用收据，可能把系统故障显示为普通证据不足。

删除这两层错误转换，审核失败保留原始异常向上传播，聊天入口现有统一处理返回 HTTP 503 并停止回答。完整输入超出预算时在发送前直接报错，不裁剪、不重试、不返回部分审核结果。事实审核要求已完成的问题方面审核；解析失败不再伪造空方面或空判断。生产代码净减少 67 行，未增加错误框架、配置、关键词规则或分类器。

合法无候选、完整审核后无支持、合法部分事实覆盖、明确否定事实和多来源互补仍按业务结果返回。历史不可用收据的只读验证保留，不能把审计记录提升为证据；当前审核不再制造这种故障收据。用户原始问题、完整来源和否定/例外内容保持原样。
