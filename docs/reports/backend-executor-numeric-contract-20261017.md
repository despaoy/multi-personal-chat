# 执行器数字配置与超时契约精简

日期：2026-10-17。基线：`96888776d08f2eac0d2af20e0e8c6ac6e2975478`。

## 问题与修改

数据库执行器把显式配置的非法整数替换为默认值，并将零或负数强制改成 1，容易隐藏部署错误。认证执行器、密码执行器和启动入口另有重复的数字读取函数，浮点超时还允许 NaN 或无穷大进入线程调度。

在现有 `infra.environment` 中统一正整数和有限正浮点数读取，删除六处重复读取函数。缺失的可选配置保留既有默认值；显式非法值抛出含配置名称的 RuntimeError，不携带原始配置内容。认证接口、数据库执行器和两个有效启动入口共享这两个函数。

有界执行器在分配线程池或提交任务前检查超时必须为有限正数，保留既有 ValueError 类型。排队容量、取消请求、统计及运行中任务可能迟到提交的语义均保持原样。生产代码增加 57 行、删除 91 行，净减少 34 行。
