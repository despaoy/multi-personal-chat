# 身份补位实验退出生产服务

生产服务保留了一套默认关闭的身份关系补位策略，实际只有离线 `identity_candidate_audit` 工具启用。本阶段将选择算法和实验调用移入 `backend/experiments/identity_coverage.py`，生产构造参数、结果中的无消费方实验标记及相关分支一并删除。离线工具仍可显式使用 `--identity-coverage`，历史实验记录保留；应用不会导入实验模块。

同时修复离线工具仍访问已移除的 `service.retrievers` 多索引映射的问题，改为观察当前单一检索器。观察器在成功和异常时都恢复；加载、排序或输出失败直接报错，已有部分输出不伪装成完成。生产代码新增四行、删除 27 行，净减少 23 行。

验证结果：

- 96 个直接相关用例最终通过，无失败或跳过。只补跑五个失败项，没有重复全量回归。
- 保留修改测试中的全部 165 条既有断言；实验 helper 的迁移只更新调用所属模块和参数名。一组旧分数测试缺少查询分析新增字段，已在未改动的运行时和分数适配器上复现相同错误，再改用真实 `QueryAnalysis` 补齐前提；负分、阈值优先级和故障断言保持不变。
- 语法树对照证明：旧生产服务按默认关闭实验特化后，与新生产服务一致；移出的选择算法本身也保持 AST 一致。原有身份、关系、可见性和来源过滤未在本阶段取消。
- 36 组排序对照的顺序、分数、方法标签和请求上限一致，覆盖身份、标题及开放问题、不同返回数量、模型／确定性排序和显式实验开关。
- 两条真实语料查询前后选中结果、分数、方法、上下文和来源目录哈希一致。修复后的离线 CLI 在真实单索引和向量模型上运行成功，记录 60 个召回候选、58 个归属过滤后候选及三个选中结果。原始作品记录仅保存在服务器，带回的只有计数与哈希摘要。
- 本阶段没有语义审核或回答模型调用，不声称新验证了模型回答质量。静态检查无新增问题，差异格式检查通过；部署后前后端均为 200，配置与其他服务未变。

后续问题已用完整虚构证据复现：双任务请求同时询问两人的关系与其中一人的导师任命经过，旧关系正则会把整体范围限定为前一对人物，在排序前删除已有完整原文的导师关系资料。该复现使用明确的语义绑定测试控制，不计为真实模型判断，本阶段尚未修复。下一阶段应让检索范围遵从完整语义任务，保留现有归属和权限校验。

身份／关系问法识别、整部作品覆盖、模型预算和自然语言姓名歧义仍需继续推进。整体目标保持进行中；密钥、运行数据及私有原文不提交。
