# 回写回执不再静默省略未完成状态

服务器隔离复现确认：实际回写生产者在操作仍 pending 时，Web 提示函数
返回空提示；返回对象缺失和不支持的来源状态也会因为默认空值被忽略。
投递 worker 已保留未完成语义，Web 入口的解释需要补齐。

## 修改

- 删除三处 getattr 空默认，直接读取实际回写结果的必需字段。
- pending、cancelled 和 unknown 明确反馈结果未确认；not_scheduled 明确
  未受理，版本冲突明确未完成，不让它们消失在正常回复中。
- 无法识别的回执进入既有“保存状态尚未确认”处理，不猜字段或伪造成功。
- 正常 no_change、已接受后台任务、无写入任务，以及既有部分保存、原文
  保存失败、禁用和容量提示保持原语义。已经生成的回答保留，提示独立
  返回并使用既有归档反馈流程；未知结果不代表线程写入已回滚。

只调整 Web 的回执解释，产品代码净增 9 行。没有增加框架、配置项、意图
规则或新的错误包装；生产者、模型输入、写入器和投递 worker 没有修改。

## 验证

- 44 项定向检查一次通过，没有全量回归或新增真实模型调用。
- 实际 complete_turn 生产者携带各类操作回执时，提示可见，计数正常，
  已处理的操作不会重复调度或重复捕获来源。
- 完全缺失结果、缺字段和未知状态不能被当成无问题的完成；正常后台
  受理仍没有错误提示，计数失败与未确认操作可同时显示。
- 原有部分写入、两种提供商下的回复与既有检索提示、归档失败、容量拒绝、
  超时后写入继续执行及外部取消检查通过，私有异常正文不进入提示。
- 旧测试桩改为完整的实际回执类型。原先 unsupported_scope 的无提示
  预期加强为“尚未确认”；原断言正文保留，没有放宽检查或删除用例。
- 静态逐函数比较确认，仅回执提示函数改变；归档、回复合并、超时与
  取消处理、回写生产者及模型代码均未改变。语法、静态与差异检查通过。
- 已部署服务器，后端就绪及前端登录页均为 200；未登录资料和生成接口
  均为 401，配置及其他服务未改变，再按摘要同步本地。

本阶段不重测模型质量。测试原文、隔离数据库、运行日志及凭据不进入提交。
