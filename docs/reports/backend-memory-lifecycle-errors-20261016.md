## 问题与修改

数据库的状态与关系列已有明确迁移默认值，但仓储返回时未验证这两个字段。隔离 SQLite 基线中，空关系被读取为普通记录；后续服务可能按 `ADD` 解释。发送前的版本校验遇到损坏状态或关系，也可能仅当作记录变化移除记忆而继续回答。

仓储现在使用同一规范枚举检查类型、状态与关系。写入复用该检查，取消关系参数的字符串化、空值兜底和大小写修正；调用方需使用协议规定的关系值。写入时省略关系仍明确采用签名的 `ADD`，`PENDING` 对应待确认状态的业务默认继续有效。

新增具体 `MemoryRecordError`，携带安全字段名；JSON、证据、来源元素和生命周期错误使用同一类型，不包含坏值。API 角色准备明确返回 503，包含 `stage=memory_read`、`reason=invalid_memory_record`、字段及修复提示，保留异常原因。事件特有错误仍保留已有响应。

读取仍遵守原作用域和活动状态过滤。历史读取、精确读取及发送前校验实际拿到的损坏记录会报错；合法缺失、撤回及删除继续按已授权证据变化处理。没有扫描其他所有者、改写历史记录、模型替代或重试。
