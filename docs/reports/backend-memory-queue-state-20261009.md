# 后台记忆在途状态去重（2026-10-09）

_inflight 原先在接受、拒绝、缓冲提交、完成和关停分支单独增减，并用 max(0, ...) 掩盖计数下溢。其值实际等于缓冲任务数加排队任务数加处理中任务数。改为只读派生属性，保留既有只读探针使用方式，删除六处重复赋值。不改变总任务容量、按 scope 顺序、超时不取消已接受任务或关停回执语义。

容量来源测试不再直接把计数设成 1，而是提交真实 idle 任务占用容量；需要空容量的场景明确通过夹具参数选择，并统一清理 scheduler。新测试覆盖 buffered→queued→processing→完成→再次接受，并确认满容量拒绝及 FIFO 次序。

服务器最初 13 项通过，旧超时测试因合成 ERASE 提案缺少当前必需 attributed_to 而在提案校验失败。补齐 attributed_to=user 后仅重测失败项及共用夹具直接影响的自然删除/非授权边界，共 12 项通过（0.58 秒）；累计 25 项相关检查，不修改有效断言。已通过的容量、来源和关停检查未重复运行。

未运行全量回归或付费模型。测试使用明确替身及真实合成 SQLite 来源存储；新的队列状态测试隔离模型处理，仅验证实际调度流。生产仍使用单事件循环调度，不新增跨线程调度支持。
