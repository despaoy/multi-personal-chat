# 收敛仅为测试保留的生产接口

## 审查与修改

按已跟踪 Python 源码核对引用后，区分离线评测、训练、人工审核工具与真正冗余接口。保留仍有工具用途的实现，本阶段仅处理两处已确认没有业务调用的函数：

- 删除 `db.adapter.get_db`：业务直接使用适配器导出的 `db`，该函数只返回同一对象。数据库选择测试改为检查正式导出的对象，继续验证仅加载所选数据库及配置、依赖失败行为。
- 删除 `reset_grounded_answer_service`：它仅被一个测试使用。测试改用现有 `monkeypatch` 设置并自动恢复两个单例状态变量，保留预算改变、服务重建和缓存更换的所有断言，避免测试结束时清空此前状态。

两个生产文件除上述函数删除外，其余代码语法树保持一致。生产代码减少 12 行；没有增加生产校验、兼容接口或回退。

## 验证

服务器上两个相关测试文件共 27 项全部通过，无跳过，涵盖数据库选择及启动错误、问答预算限制、流式与非流式生成以及预算变化后的服务缓存更新。静态检查、仓库完整性和差异检查通过。

重启后后端就绪及前端登录接口返回 200，未登录访问受保护接口返回 401；配置与前端进程未变化。服务器验证后，按内容哈希将四个源码与测试文件同步至本地。

本阶段没有真实模型调用，没有重复运行全部回归测试。
