# 主体、来源与删除保留契约整理

## 生产修改

事实提议的主体校验删除了无用的归一化返回值和静默跳过分支。缺失或无效主体标签现在使用已有的 `MemoryResponseError`，明确返回 `attributed_to` 字段；已有检测发现模型把他人的事实写给用户时，返回 `content` 字段。

没有新增主体判断规则、正则或异常包装，生产代码净减少 2 行。合法标签集合不变，原话观察仍与本人事实分开处理，完整来源继续保留。

## 测试前提与断言

- 补齐合法提议必需的主体字段；未声明的模型“保护条目”字段明确失败。保留范围仍由后端原始授权决定，不能由模型自行填写。
- 缺少必需数据库接口时保留原始接口异常，不再要求恢复已删除的旧适配器回退。
- 来源状态传输测试提供完整规划控制、原始文档快照与对应读取接口，继续检查警告只出现一次，且不增加回答调用。
- 没有跨会话授权的别名样例明确测试当前会话范围；范围校验仍拒绝未授权请求，没有恢复自动降级。
- 原“范围不明”删除样例实际上能解析出删除对象与大学专业保护对象，并进入了未配置返回值的模拟模型。改用确实无法确定的保留指代，并先验证 `unresolved_protection`，继续要求模型不被调用、所有记录不变、删除请求不进入原话池。
- 不支持的显式采样参数继续失败，配置与调用次数检查保留；HTTP 状态与当前配置错误契约一致。
