# 重排序模型路径单一来源（2026-10-09）

## 问题与修改

`RerankConfig.model_name` 曾在模块导入时读取环境变量，之后新建配置仍可能使用旧值。模型加载失败后还会尝试把配置路径解释为另一目录，掩盖实际配置错误。

改为构造配置时读取当前 `RERANKER_MODEL_PATH`，显式构造参数仍优先。分词器和模型只使用该配置值，失败保留原始异常并清理半成品。未配置时的内置模型目录不变；显式相对路径按进程当前目录解释，不再另试 backend/knowledge 下同名目录。已有评测脚本传入绝对路径，不受此变化影响。

删除没有任何实现或调用者的 `enable_quantization` 字段，并纠正文档中“支持 4bit 量化”的失实描述。没有删除已实现的量化能力。业务代码净减少 34 行。

## 验证

服务器仅执行重排序测试中的加载、路径配置、离线和显式下载相关项目：12 项通过，23 项未选中，2.04 秒。覆盖构造时读取环境、显式路径优先且不改写、相对路径失败只尝试一次、默认离线、下载必须启用、失败后恢复，以及空/单候选加载行为。

语法、增量 Ruff、差异检查通过。模型组件显式使用测试替身，未下载模型或发起 API 调用，未重复全量测试。生产配置和数据未修改。

此项不包含真实模型质量验证，也尚未调整设备自动切换逻辑；其他模型适配器的路径策略需独立审查。
