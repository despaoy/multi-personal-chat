# 角色索引故障与范围外查询分离（2026-10-09）

## 问题与修改

`MultiScaleRagRuntime._ensure_loaded` 曾把文件缺失、解析或索引构建失败转换为 False，再由检索入口转换为 None；与正常范围外查询混淆。失败详情还会直接进入日志和状态。

- 删除加载吞错与未使用的 `_load_attempted` 状态，保留原始异常传播。索引服务完成构建后才发布到实例。
- 空查询、通用知识库过滤、其他知识域和无关查询先完成范围判断，不触发角色索引加载；范围内请求必须成功加载，否则报错。
- 异步预热作为后台优化只记录错误类型，不输出私有异常文本；真实请求仍重新尝试加载并传播故障。
- 保留原有加载锁、成功缓存、证据不可信标签及正常无匹配行为。

业务代码净减少 7 行，无新依赖、配置或生产数据变更。
