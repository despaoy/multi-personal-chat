# 筛选条件下候选截断的漏召回修复（2026-10-09）

纯向量搜索先取 top_k*5 再筛选，混合关键词先取 recall_k 再筛选，前面的不匹配记录会占满候选窗口，使实际存在的合格证据返回空。向量路径保持原初始窗口，结果不足时按倍数扩展到文档总数，达到结果数、总量或分数下界时停止；编码仅执行一次。BM25 增加可选候选位置集合，在计算/排序前应用元数据筛选，删除排序后重复过滤。

服务器六项定向测试通过（1.76 秒）：32 条完整规则记录中，只有末条属于目标集合，纯向量和仅关键词命中路径都找到末条；不存在的集合返回空；目标向量低于阈值仍不入选；四项既有关键词身份/筛选验证通过。使用真实 FAISS/BM25 与显式编码替身，四条警告来自既有依赖。

没有全量回归或付费模型调用。向量扩展在稀疏筛选时会增加索引搜索次数，但不额外调用嵌入模型。测试使用 Flat 索引；IVF/HNSW 的近似召回仍受其本身搜索参数影响，不声称本次保证所有近似索引百分之百召回。没有增加无关证据补齐或修改分数阈值。
