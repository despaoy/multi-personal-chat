## 问题与修改

构造器声明接受 URL 列表，实际直接调用字符串方法，列表不能使用。空地址会改用其他环境配置或默认地址；显式超时 0、尝试次数 0 会被默认值替换，负并发又被夹到 1。单例工厂重复解析环境配置，空 API key 也会被环境密钥替换。

现在构造器统一接收 URL 列表或逗号分隔字符串，只在参数缺省时读取环境。URL 配置优先级为显式参数、`VLLM_BASE_URLS`、`VLLM_BASE_URL`，只有两项环境设置均缺省才使用原本的本机开发默认地址；显式空列表、空字符串或空条目直接报错。显式空 API key 表示不发送认证头。

超时、尝试次数及并发复用现有正数配置读取器；显式参数覆盖环境后只解析一次，不再替换或夹高无效值。单例只创建构造器，实例列表使用直接的列表构建。生产代码净减少 13 行，没有新配置框架、额外校验层、重试或模型切换。`VLLM_MAX_RETRIES` 继续表示含首次请求的总尝试次数，仅修正文档歧义，调用循环未改动。
