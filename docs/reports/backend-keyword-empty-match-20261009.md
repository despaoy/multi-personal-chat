# 关键词零分候选不再补齐结果（2026-10-09）

BM25 默认 threshold=0，原先 score>=threshold 会把完全没有词面匹配的文档作为零分候选返回。混合搜索即使没有向量证据也会接收这些文档，上层查询加分还可能使它们看起来具有正分。现在关键词候选必须得分大于零且达到请求阈值，合法无匹配返回空；有向量证据但关键词零分的文档仍可由向量通道入选。

无全量回归、真实或付费模型调用。此检查只要求关键词通道有实际匹配信号，不把任意正 BM25 分数等同于充分证据；后续相关性和证据覆盖判断仍需各自执行。
