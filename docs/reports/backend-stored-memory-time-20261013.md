# 存储记忆时间统一解析并明确失败（2026-10-13）

## 问题与修改

CharacterMemoryService 的当前/历史筛选与 context_builder 的参考区编译原先各有一套时间解析，非法日期均返回 None，可能将损坏有效期变成没有期限；损坏更新时间也会变为零新近度。有效期字段选择使用 or，还会吞掉 0、False 等错误值，转用旧字段或空值。

删除两套重复解析，统一使用现有 memory_clock 模块中的 parse_memory_timestamp。合法 None/空时间保留未指定语义；非法 ISO 日期和结构错误明确报错并说明字段。已有无时区历史存储保持 UTC 解释。当前与历史读取共用有效期字段选择，只有真正未提供规范字段时才读取旧别名，错误值不再被跳过。生产代码净增加 1 行，无新增模块或配置。

## 验证与限制

服务器 68 项直接相关测试通过（0.72 秒），40 项未受影响测试未重复运行。覆盖四个有效期字段的六类错误在当前/历史查询中报错、损坏更新时间、参考区有效期/观测时间错误、合法空边界、UTC 与 +08:00 的半开区间、旧字段优先级，以及既有当前版本、历史月份和明确参考时钟场景。语法、差异检查通过，无新增静态问题。使用完整合成资料，未运行全量回归，付费模型调用 0。

本阶段验证存储时间解析与传递，不修改历史数据、不改变自然语言查询时间识别，也未审计所有其他日期生产与投影路径。整体目标继续；后续应核对无效查询时间是否被扩大为泛历史范围，以及重复证据转换中的错误处理。
