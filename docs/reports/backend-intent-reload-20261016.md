# 意图分类器训练与重载失败显式化

日期：2026-10-16。基线：`5b3423320d52c6cce36ccb5c06bdb87e2c63b096`。

审计管理界面 → 训练 API → 后台训练任务 → 模型重载的完整调用链，并确认独立 CLI 也是二分类训练产物的实际写入方。隔离复现中，训练产物已保存但重载编码器失败，原任务仍返回 stage=done、success=true，分类器实际不可用。旧加载器还会尝试不同编码器来源、历史目录和规则判断，交叉验证异常则被改成零分后继续报告完成。

现在训练与 CLI 共用模型目录和编码器工厂，只使用明确配置的本地编码器，并把实际来源保存到产物配置。重载严格读取指定目录的配置、分类器和 scaler，使用产物记录的编码器来源；缺失、损坏或构造失败直接传播，不自动换目录、换来源或改用规则。预测的正负结果均由该分类器决定。保留显式离线规则实验工具及 CLI 二分类格式，没有删除历史训练文件，也没有把分类器接入当前 DeepSeek 主对话。

训练成功必须包含产物保存和重载完成。已保存但重载失败时保留路径、准确率等实际结果，同时明确 success=false、artifacts_saved=true、reloaded=false；交叉验证失败不再伪造零分。读取产物放在线程中，发布可用模型放回事件循环并检查取消状态，避免取消后线程迟到发布模型。共享加载流程同时移除了重复实现。

服务器 15 项定向测试通过（6.05 秒）：训练/重载契约 9 项、既有预测失败传播 3 项、既有任务生命周期 3 项。测试包括真实后台 HTTP、完整 12 条平衡样本、真实 sklearn/CV/scaler/joblib 往返、目录及 scaler 缺失、编码器构造失败、交叉验证失败、正负预测权威性，以及线程读取期间取消后的状态和发布检查。移除了与新契约冲突的混合规则/自动回退测试，保留预测异常原样传播检查。编码器权重使用明确的合成替身，这些测试不证明真实模型语义质量。

独立 CLI 导入检查通过：与后台任务使用完全相同的目录和编码器工厂，未执行训练。语法、增量静态检查及差异检查通过；部署只重启后端，检查就绪、配置及其他服务，再按 SHA 同步本地、服务器 Git 和 GitHub。没有调用 DeepSeek 或下载模型，没有提交运行数据、密钥或私有测试原文。
