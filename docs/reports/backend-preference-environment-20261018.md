# 偏好训练独立环境验证

日期：2026-10-18。代码基线：`9bcd565`。

此前三条真实 CPU 训练集成测试在主后端环境中失败，原因是该环境的 TRL 不支持项目要求的显式 SFT 参考适配器契约。项目已经通过 `backend/requirements-preference.txt` 声明单独的训练环境；本阶段按照该文件准备隔离环境，没有修改运行中的后端依赖。

训练测试环境使用 Torch 2.8.0、TRL 0.23.1、PEFT 0.17.1、Transformers 4.56.2、Accelerate 1.10.1、Datasets 4.1.1。既有 Torch 二进制依赖被复用，指定训练依赖安装在独立目录，主环境版本前后完全一致。

原有 `test_preference_real_cpu.py` 的三条用例全部通过，测试源文件和断言均未修改：

- 普通和对话格式的 DPO、普通格式的 ORPO 均完成两步真实 CPU 训练及留出集评估。
- DPO 的 SFT 参考权重哈希前后一致，训练前相对参考奖励为零。
- 导出的策略适配器可以重新加载，策略权重确实改变，参考适配器没有混入导出目录。

测试使用本地构造的合成微型模型，没有下载模型、调用付费 API 或使用真实角色语料。训练输出、依赖目录和原始日志留在运行目录，不进入 Git。

最终整体验收应采用两组明确环境：主运行环境验证后端，其独立训练环境执行这三条 CPU 集成测试；两个结果都必须成功，不能在主环境跳过后就宣称训练验证通过。本阶段已实际完成独立训练验证，剩余待审记录为 38 条，整体优化和最终整体验收继续进行。
