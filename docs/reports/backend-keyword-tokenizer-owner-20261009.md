# 关键词分词单一实现与明确失败（2026-10-09）

持久向量索引的 BM25Retriever 和域内 BM25Index 各维护一份几乎相同的中文分词逻辑，且都在 jieba 缺失时静默改用单字。jieba 已在 backend/requirements.txt 声明为必需依赖。合并到 retrieval_core/tokenization.py，保留原有英文/数字正则和 jieba 中文词规则，删除两处备用分词、无用正则导入及返回前冗余空白过滤。

分词依赖在首次实际使用时导入，缺失会以包含 jieba 名称的导入错误失败，修复方式为安装项目声明依赖；jieba.cut 本身异常同样传播。不新增模型切换、配置或兼容包装。

服务器八项定向测试通过（1.63 秒）：两种索引的中文命中与无结果；两种索引在缺失 jieba 或分词故障时，构建和查询均报错；既有稀疏筛选召回两项通过。四条警告来自既有 jieba/pkg_resources 依赖。实际运行确认服务器已安装分词依赖。

无付费模型或全量回归。正常分词规则保持一致，不修改快照格式，也未重建生产索引；历史上由缺依赖环境生成的单字索引不在此次测试范围。
