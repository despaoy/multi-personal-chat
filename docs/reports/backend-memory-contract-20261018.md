# 记忆字段与模型时间协议收敛

日期：2026-10-18。基线：`556bd7c`。

## 实际问题与修改

完整的四项本人资料通过实际配置的 DeepSeek 记忆模型提取时，籍贯被输出为通用事实；即使使用原有 `location` 类型，字段映射仍无法明确区分籍贯与现居地。写入协议现在明确提供 `origin`、`residence`，直接映射到已有的 `user_origin`、`user_residence`，复用主体归属与目标字段检查。没有新增关键词、正则或分类器。已有 `location` 调用契约保留，存量记录无需迁移。

新模型响应只使用顶层 `valid_from`、`valid_to`。删除从 `valid_at`、`invalid_at` 和 `qualifiers` 中挑选、提升时间值的修补逻辑；非法协议明确报错。存量数据库记录的旧日期别名读取不变，发言时间仍由服务器记录。

完整原话观察的提示约定要求 `content` 留空、`qualifiers` 使用空对象，直接保存整条来源及末尾条件，避免再次概括同一组限定。解析器仍拒绝不受来源支持的限定，没有忽略非法输出或自动切换模型。

更新旧测试中“非法限定返回空成功结果”的预期，改为检查明确的协议异常；删除操作使用已声明的类型。压缩重复的旧时间布局组合，保留日期精度、服务器时间、虚假当前状态与存量数据读取检查。
