# 关闭自动语义记忆时不再改用规则写入

日期：2026-10-16。基线：`d6fde4cb72f0d8b81900f4b4109c044947704fd5`。

## 问题与修改

服务器隔离数据库复现：MEMORY_LLM_ENABLED=false，complete_turn 仍返回 rules/saved 并写入一条偏好。原路径是自动算法切换，而非显式选择的离线工具。

删除 CharacterContextService 的自动规则写入循环及导入；未启用语义写入时结果明确为 disabled/disabled，不自动创建记忆或来源。Web 提示“自动长期记忆未启用；本次回复不代表已保存”，并将完全相同的实际回复写入存档。持久投递保留已发送回复、已完成计数和回执，终止为 blocked/memory_disabled，不标记保存成功、不自动重试。

原有真实失败、撤销、冲突和必需回写失败的优先级不变。显式备忘录、事务称呼更新、交互计数和删除操作回执仍走既有独立路径。直接调用的历史 rule_memory_writer 工具保留，生产 complete_turn 不再自动调用。没有新增配置、模型调用或语言规则；三个生产文件合计净减少 7 行。

## 测试精简与验证

删除两个旧“关闭模型后规则保存成功”的 completion 测试及两个规则故障参数用例，新真实 SQLite Web/投递两项覆盖替代契约。六项必需回写用例按新 disabled 状态更新，全部失败、隐私、地址事务断言保留。十项时钟用例改为显式 extractor→历史 writer 工具调用，保留所有时间、跨月跨年和闰日断言。两项长历史召回先通过真实仓储准备已保存姓名，保留无聊天历史和用户隔离断言。

提供商归属测试的两个持久化用例显式安排 enabled 合成 no_change 边界，避免依赖被删除的关闭模式；实际来源捕获、计数、消息、模型调用记账及数据库归属仍执行，原回复和持久化断言没有放宽。该合成结果不代表新的语义模型验证。

服务器共 27 项直接相关测试通过（3.56 秒）。新用例对自动规则、实际模型和 embedding 边界设失败探针，核实 disabled 不创建 claims/sources、不调用模型，且 durable 真正再轮询后不会重复执行。显式 notes、小说排除、enabled 调度失败及部分保存提示也通过。仅有依赖 TestClient 的既有 anyio 弃用警告。

语法、增量静态及差异检查通过；未调用 DeepSeek、未加载真实权重、未跑全量回归。当前凭据的真实模型验证仍未执行。本阶段仅重启后端并验证就绪、配置与其他服务，按 SHA 同步本地及 GitHub；不含密钥、运行数据或私有用户原文。
