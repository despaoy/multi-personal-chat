## 实现

删除preference_index.py及其调用分支，取消条件标签、AND等价和必要/充分条件的规则修补。对象使用模型明确给出的合法原文值，完整条件和否定独立保存；无来源索引明确报value错误，事实写入前整批失败。正常条件偏好、文字中真实存在的括号对象、like/dislike、AND/OR、必要/充分条件、未来生效及旧版本保留继续验证。

更强的合法短索引案例又暴露旧缺口：整段引用可能被当成本人事实。加载修改前模块确认同样发生。现在事实提议复用已有引号解析器，纯引用不能晋升为本人事实；带引号的对象名称仍可出现在本人声明中。原文观察与来源保留独立，不新增语义词表或分类器。

真实测试显示模型理解了对象，却反复概括限定文字。将这一环节改为显式来源引用：payload提供按结构标点定位的qualifier_sources，模型可在限定值中指定{"source_unit":"q编号"}，后端读取那个完整原文片段。未知编号、混合字段或片段未被本条evidence覆盖均报qualifiers错误，不猜编号、不把概括字符串修成原话。普通字面标量仍是现有调用方和记录的合法协议；跨片段限定可显式逐字提供完整连续原文。钟点09:30等不会按ASCII冒号拆开。引用只负责来源定位，语义关系仍由模型判断；授权、主体及版本检查保持原边界。

合并重复提示，明确value为对象、qualifiers为业务限定、scope_level为可见范围，保留原文时间限定与顶层有效期。没有增加服务、配置、数据库迁移、额外审核模型或隐式降级。生产代码净变化-52行。
