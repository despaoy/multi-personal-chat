# 检索资源首次创建与权重加载保持唯一所有权

日期：2026-10-18。基线：`84fb23afc82d133de1a2d8da055319f8ee90f487`。

沿知识检索、RAG 辅助器、原生重排和实际线程入口审查，确认三个全局 getter 没有初始化同步：并发首次调用可以分别取得不同索引对象、缓存或重排器。共享重排器的 `_load_model` 同样没有同步，多个调用会重复加载并相互覆盖分词器和权重。索引对象各自的锁无法约束另一个实例，部分 API 重建锁也不能保证这些公共 getter 的所有调用方共享同一所有者。

以八个受控并发调用复现：三个 getter 各创建并返回八个实例；同一重排器的首次加载也分别加载了八次分词器和权重。构造器及权重均受控，没有加载真实模型或写入用户索引，不据此声称已复现实际数据丢失。

三个资源入口各在一个锁内完成现有判断、创建与发布；共享重排器以实例锁覆盖现有加载流程。**生产代码增加 9 行，条件检查数量不变**。剥离新增锁及其所有者后，生产模块语法树与修复前一致：路径选择、配置优先级、模型参数、设备选择、清理、异常和推理执行逻辑均保留。没有双重检查、自动重试或新配置项。

修复后同样的八个调用只得到一个实例，分词器和权重各加载一次。首次构造失败仍把原异常交给当前调用方，不发布半初始化对象，锁正常释放；后续独立调用可以重新创建，成功后继续复用同一实例。

新增七项并发及失败恢复回归。只运行 11 个相关模块，**136 项通过，无失败或跳过**，覆盖资源取得、重排参数与错误、缓存、索引写入及完整通用检索。前后七组受控场景和静态错误、语法、差异格式检查通过。未重跑全量回归，未调用付费模型。
