# 精简通用索引编号编码

日期：2026-10-17。基线：`b2dee237904bb8769e237965b7e4a7a10bf7af8d`。

## 问题与修改

`VectorDatabase._to_faiss_id` 在多个分支重复执行相同的整数范围处理，并通过宽泛异常捕获返回 `None`。无效编号随后变成笼统的索引身份错误，原转换位置不清楚，错误日志还会包含原编号。布尔值和小数也会被当成整数，例如 `True` 和 `1.75` 都编码为 `1`。

现在只接受整数类型或非空字符串；NumPy 整数同样按整数处理。合法数字字符串、十六进制前缀和普通字符串继续使用已有持久化编码，范围处理只执行一次。无效类型直接报告编号错误，编码异常直接传播，不返回空编号或换一种编号掩盖失败。重复编号仍由现有完整性检查拒绝。

生产代码增加 19 行、删除 41 行，净减少 22 行。除该编码函数和必要导入外，向量模块其他函数的语法树保持一致。索引格式、快照发布、检索排序、查询缓存、模型及提供商配置没有改变。
