# 清理同步完成回执中的旧计数

基线：1d29b28。生产修改仅涉及 `backend/services/character_context.py`，净减少一行，无新增分支。

## 架构判断

生成后的同步完成服务负责交互统计、来源保存、任务提交和称呼更新。结构化记忆由异步写入器实际持久化，其回执负责记录 accepted/persisted 和部分成功状态。原 `_TurnOutcome.new_memories` 从未被赋值，始终为 0，却被用于异常分支的部分成功判断，并出现在诊断序列化结果中。

删除该无效字段，将异常路径明确标为 failed。仓库范围检索确认没有业务消费者读取该字段；已有历史诊断记录不作迁移或删除。显式操作回执传入的 partial 状态、网页部分保存提示和投递端部分写入处理保持不变。
