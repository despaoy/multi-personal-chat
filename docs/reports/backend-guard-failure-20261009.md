## 问题与修改

generation_request.py 的实际生成路径有两处替代成功：无记忆命中时，不受支持的用户事实直接替换为固定回答；一次修正后仍违规时，使用固定回答或删句整理后返回成功。部分无法替换的违规甚至继续返回原文。

- 删除两个替代分支和重复的替代结果验证。模型输出最多修正一次，仍存在所选策略的阻断规则时抛出 ReplyValidationError。
- API 在原有失败计数和调用失败记录之后返回 503，注明 reply_validation 阶段、model_output_invalid 原因和规则编号；不记录或返回模型原文。
- 保留一次修正前的证据重验证、上下文预算和历史裁剪；不把失败原文重新加入提示。
- 正常无匹配仍可由模型如实说明证据不足；当前策略允许的风格诊断继续作为诊断，不被误判为新的硬错误。
- 冻结回放工具不再把无匹配推演为立即固定回复。七个旧生成测试改为保留原始场景并断言失败，其余无匹配和轻量校验测试更新为同一失败合同。

生成/API/回放代码合计净减少 32 行，无新增配置、依赖、数据库迁移或历史数据更改。独立 deterministic_fallback 函数和直接单元测试暂留待下一项清理；生产生成链及冻结回放已不调用它。历史 guard_fallback 字段仍有回放、引用处理消费者，本阶段未移除。
