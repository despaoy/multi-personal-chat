# 知识库搜索 API 移除三级降级（2026-10-09）

## 问题与修改

`POST /api/knowledge/search` 曾在完整 RAG 失败后切换直接向量查询，再回退全库关键词扫描；索引重建失败也会走关键词分支。正常无匹配亦触发额外搜索，故障可能伪装成成功结果。

删除两个回退实现和重复响应拼装，保留一条完整检索路径。索引未就绪、数据库或 RAG 错误统一返回 HTTP 503，并提供检查索引、数据库和模型的恢复提示；保留异常原因供内部诊断，日志和响应不输出异常原文。正常无结果返回 empty，指定知识库不存在仍返回空结果，不扩大到全库。请求继续使用既有管理员依赖。

业务代码净减少 92 行。显式 use_cache=False 替代旧位置参数 None，保持该管理搜索入口不复用查询缓存的既有行为。生产数据和配置不变。

## 验证

服务器只执行知识搜索响应契约及三个直接受影响接口测试：10 项通过，3.03 秒。

覆盖索引未完成、索引异常、初始化异常、检索异常、数据库异常、错误内容脱敏、正常空结果不触发另一检索器；使用真实临时 SQLite 中的两个知识库交叉验证过滤范围，保留不存在知识库的空结果检查。

将过期的“失败后关键词成功”测试改为明确失败契约，将旧回退范围测试迁移到正常检索路径，保留不同知识库不能串数据的断言。静态检查发现新增测试导入位置问题，已整理并通过语法、增量 Ruff 和差异检查。未运行全部回归，新增模型调用 0 次。

## 限制

RAG 执行部分使用显式组件替身，本阶段没有新的真实模型质量评测或 HTTP 网络端到端测试。索引重建内部仍有返回 False 的旧错误转换；本接口已将其视为失败，内部诊断和其他接口需后续独立梳理。历史响应类型定义暂保留兼容，当前搜索不再产生降级结果。
