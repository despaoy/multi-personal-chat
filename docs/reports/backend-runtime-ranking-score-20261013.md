# 检索门控不再替换重排低分（2026-10-13）

## 问题与修改

实际调用链为 MultiScaleRagRuntime.retrieve_with_citations → GroundedAnswerService → /api/ask。启发式重排分数非正时，运行时原先改用 fused_score × 8，可能将不相关候选提升到可回答门槛。损坏或非有限分数还可能被解释为正常低置信度弃答。

现在只使用最终重排分数：合法低分保持低分并按门槛弃答，不换用召回融合分；布尔、缺失或非法数值明确失败。空结果仍是正常弃答，cross-encoder 仍按原始 logit 门槛判断，sigmoid 仅用于展示。删除已统一校验之后的重复有限性检查，生产代码净增加 1 行。

## 验证

服务器 20 项定向测试最终通过（0.44 秒）。首轮因测试不必要地初始化 embedding 资源而缺少模型路径，未触达门控；改为为组件直接提供完整结果及域分析输入后重跑，全部通过。覆盖合法 0/负分/边界分、高召回分不救回低重排分、原始 logit 判断、分数错误明确失败、空结果，以及低分不会进入回答模型。11 项未受影响测试未重测。语法、差异检查通过，无新增静态问题。

另以运行服务的实际索引、embedding 和 DeepSeek 配置，在隔离 FastAPI/ASGI 路由中调用 /api/ask，未替换检索结果。返回 HTTP 200、grounded_answer、非弃答、3 条引用，modelInvoked=true、cacheHit=false；真实 deepseek-flash 调用 1 次，输出上限 512 token。独立临时数据库，不写生产数据库。鉴权依赖由合成用户替代，未验证真实鉴权、部署中完整中间件或网络传输。
