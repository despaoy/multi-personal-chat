# 检索门控不再替换重排低分（2026-10-13）

## 问题与修改

实际调用链为 MultiScaleRagRuntime.retrieve_with_citations → GroundedAnswerService → /api/ask。启发式重排分数非正时，运行时原先改用 fused_score × 8，可能将不相关候选提升到可回答门槛。损坏或非有限分数还可能被解释为正常低置信度弃答。

现在只使用最终重排分数：合法低分保持低分并按门槛弃答，不换用召回融合分；布尔、缺失或非法数值明确失败。空结果仍是正常弃答，cross-encoder 仍按原始 logit 门槛判断，sigmoid 仅用于展示。删除已统一校验之后的重复有限性检查，生产代码净增加 1 行。
