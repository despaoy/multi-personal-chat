# 结构化纠正检索统一轮次记录（2026-10-09）

CorrectiveRetrievalAdapter 原先仅在重试成功时标记 reformulated，重试低置信度或改写后未命中域会漏记实际执行的改写；同时首轮/重试有重复读取和记录，缺字段用默认值掩盖，非法重试数会被 int/max 静默转换。

现在单一有界循环记录每轮，实际发起改写时即记录其查询；决策字段直接读取，缺失明确失败；重试次数要求非负整数。None 仍代表正常未命中域，改写后 None 保留最后一轮域内证据而不伪称该改写成功。成功后的证据合并算法保持不变。

服务器 18 项定向测试通过（1.51 秒）：重试低置信度/未命中域/成功三种结果均真实记录，输入不被修改；首次未命中/成功/无新增词/零重试仅检索一次；首轮或次轮缺决策字段报错；五种非法次数被拒绝；次轮超时不返回旧证据；既有服务将检索失败标记为 retrieval_unavailable 且不调用模型的检查继续通过。四条警告来自既有 jieba，无全量回归或付费模型。
