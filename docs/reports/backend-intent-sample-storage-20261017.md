# 样本文件原子保存与编辑接口收口

日期：2026-10-17。基线：`c204919060a2e28832823d51d7062470827656de`。

## 问题与修改

服务器隔离复现四个实际问题：序列化失败前已经截断旧文件；统计计算失败发生在新内容写入之后；批量接口缺少 `samples` 字段仍清空文件并报告成功；读写异常原文直接进入接口错误响应。

生成与编辑继续共用 `save_samples`。该函数先计算统计和完整 UTF-8 JSON，再在同一文件系统的私有临时目录写好候选文件，关闭写入后原子替换正式文件。候选文件使用 0600 权限；临时目录交给标准库管理，成功、写入失败、替换失败及取消都会执行清理。正式替换前的失败保留原文件，新文件创建失败也不留下残缺正式文件。没有增加通用文件框架、重试或旧数据替代返回。

新增三个简洁请求模型，单条添加、修改和批量保存的必要字段与类型由 API 边界统一校验。修改索引必须非负。批量请求必须显式提供 `samples`，错误结构返回 422；显式空集合仍可清空，正常前端请求结构保持兼容。

五个样本读写接口共用安全错误转换：系统故障返回 503，提示检查文件、空间和权限，保留异常原因，仅记录异常类型。样本不存在仍返回 400，尚无样本文件仍是正常空结果。移除批量接口对缺失统计的空字典替代和重复成功结果拼装。

生产代码增加 51 行、删除 24 行，净增加 27 行；新增部分用于原子发布、请求模型和共享错误说明，无新增依赖。
