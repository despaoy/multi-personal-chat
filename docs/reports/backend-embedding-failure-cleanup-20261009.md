# 本地嵌入失败处理精简（2026-10-09）

## 修改

共享 SentenceTransformerEmbeddingProvider 和通用 VectorDatabase 在 GPU 模型加载失败后曾自动改用 CPU；共享 provider 还对任意编码异常重跑整批，包括输入、维度错误及已经耗尽时间预算的调用。

删除这两处设备降级、宽泛重试循环和无调用方的 max_retries 参数。设备检测异常直接传播；正常自动检测没有 GPU 时仍选择 CPU，显式 device 参数仍原样使用。加载失败保持模型未初始化，原始异常交由调用层处理，不记录未经筛选的原始错误字符串。

保留批量编码、空输入结果、维度验证及批次结束后的超时检查。这个超时不能中断正在执行的底层模型 encode，本阶段没有声称实现硬取消。

## 验证

服务器 13 项定向测试通过（0.47 秒）：两种模型入口的加载失败不换设备、设备检测失败传播、正常 CPU/GPU 自动选择、已加载实例复用、编码/维度/超时失败不重复调用、成功批次与空输入，以及现有共享路径调用测试。

测试显式使用模型和设备替身，不声称真实 GPU 推理验证。未运行全量回归、未下载模型、未调用付费模型。没有调整当前模型配置或索引内容。

部署、语法和增量规范检查、同版本同步记录位于服务器本阶段备份目录。私有原文、密钥和运行数据不提交。
