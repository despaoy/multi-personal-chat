删除基类三行空实现，让既有管理器能力判断生效，**生产代码净减少 3 行**。未新增能力表、包装或错误检查；不支持的非空请求现在明确报错，正常清空 `None` 仍成功。支持 LoRA 的提供商实现、选择范围和 HTTP 检查保持原样。

将现有回归测试中的空对象替换为真实提供商类，保留清空、拒绝、不触碰非选中提供商及支持路径的断言；未新增测试。只运行 7 个相关模块，**120 项通过，无失败或跳过**，包括真实提供商生命周期在受控权重构造下的适配器切换和失败检查。静态错误、语法及差异格式检查通过；未重跑全量回归，未调用付费模型。
