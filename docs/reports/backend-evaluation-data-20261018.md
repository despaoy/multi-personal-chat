# 评测数据加载和读取明确报告故障

基线：`d15e2d09572abb73d67e4dc8e46b31661b499daf`。先审查评测集加载、评测创建和后台回写、列表和详情、可空 TEXT 列、前端对象契约及偏好数据解析，再在服务器原生 SQLite 和真实 JWT 下复现。

## 问题与修改

Gold 模块导入失败原来返回 200 和空评测集；已知评测集文件缺失、损坏或结构错误则被归为客户端错误。评测记录的评分、分类统计和配置快照有四处独立吞错解析，损坏内容被替换为空对象，数组或 JSON null 也能作为成功结果返回。

- 删除导入失败后的空集成功响应。未知数据集名称使用标准 `LookupError`，保留原有 400 及说明；文件和解析错误保留原始原因，统一进入既有 500 错误边界。删除文件存在性预检查，直接读取文件。
- 将偏好接口已有的对象解析函数移至 `db/json_fields.py`，原实现 AST 不变，由偏好和评测共用。数据库 SQL NULL 仍表示可选字段未填写；其他值必须能解析为 JSON 对象。列表和详情删除四处捕获后默认成功的代码。
- 删除评测和反馈查询中四处空列表、计数默认值，使用已有数据库返回契约。
- 错误日志保留操作、任务 ID（适用时）和异常类型，移除异常原文及 traceback 输出，避免记录参数或原始内容；HTTP 错误继续保留原始异常原因。统一整理相关函数参数排版。

四个生产文件合计净减 7 行，没有新增错误类、重试、依赖或语义规则。SQL、原有偏好业务函数及生成评测执行、排队、回写实现保持不变。
