# 语义门控下迁移记忆与证据测试（2026-10-14）

## 问题与修改

聊天改为必要语义规划后，旧测试仍以 needs_rag 规则返回值控制检索，或把确定性答案的“没有调用回答模型”当成整轮没有任何规划调用。这些前提既不能验证当前入口，也可能在未配置审核控制时意外请求真实模型。

增加两个仅由测试显式启用的 fixture：一项阻止选定单元测试调用真实上下文审核客户端；另一项将测试明确提供的完整来源分类，通过实际 JSON 解析、依赖覆盖和业务切分检查构造语义计划。没有根据关键词替测试分类，没有改变生产模型或提供降级。测试分别统计规划与回答调用。

个人字段读取、删除执行回执、历史来源绑定及私有原文最终授权测试改为提供语义控制。共享生成路径的旧 question/evidence 占位改为完整虚构展览条款，包含费用、开放时间、雨天否定及预约例外；仍要求生产与标准生成构建器的模型消息完全一致、引用绑定正确、完整原文进入模型。相关性审核为明确的传输测试控制，此用例不证明语义审核质量。

私有来源竞态测试使用真实 SQLite 的原文捕获、召回和撤销，任务切分标识跟随审核实际输入，保留授权来源可见/撤销后不可见的断言。移除已无生产调用的旧规则控制，不删除记忆失败、引用、历史或权限检查。
