# 数据集创建与训练读取契约收敛（2026-10-19）

基线：`f405bd6640a27dc96ff3a7b5ca1a4d874f351fa0`。服务器先修改、验证及部署，再同步本地。

## 调用链与实际问题

创建 API → `DatasetPreprocessor.prepare_training_data` → 数据集清单和分区文件 → `SimpleLoRATrainer._build_config` → `LoRATrainer._load_and_preprocess_data` → `normalize_chat_record` → 助手监督标签。

前置对照使用四组各 12 条完整合成记录：Alpaca、prompt/response 能创建但训练读取失败；messages 在创建时被拒绝；conversations 能读取，但人物提示词和生成好的验证集没有被选入训练配置。训练端还会为未指定人设的记录注入无关的胡桃提示词。此前置证据对应的训练源文件与本阶段基线逐一核对哈希一致，没有重复执行前置测试。

## 修改

- `normalize_chat_record` 成为共享格式入口，支持已有 conversations、messages、旧 user_question/agent_response，以及创建端声明支持的 Alpaca 和 prompt/response。Alpaca 保留 instruction、额外 input 和完整历史问答；不改写原始事实。
- 创建端使用同一归一化结果校验并计算风格统计，原始记录仍原样保存。删除重复格式验证器、无调用的文本清洗方法，不为每种格式另写一份解析。
- 混合格式经过 Arrow 读取时，缺失列会出现 null；统一入口把这些空列视为字段未提供，必需答案缺失仍报错。没有补造文本、换用其他回答或返回模拟成功。
- 配置组装一次读取数据集清单：目录按 `file_name` 选择训练文件，`file_name_eval` 选择固定验证集，`custom_prompt` 作为系统提示词默认值。显式训练配置优先，已有 preserve/replace/require_match 策略继续控制记录内系统消息。显式文件路径保留原优先级。
- 清单指定文件不存在、不是文件或越出数据集目录时失败，不另选其他训练文件；清单自身不再被当成训练数据。
- 未指定系统提示词时保持空值，不自动指定人物。清理 5 个已确认未使用的导入绑定。

生产代码净减少 **33 行**，没有新模块层、依赖、重试、语义关键词规则或分类器。旧角色、系统消息、说话人边界及监督逻辑主体保持原样；API、数据库、推理提供商和 DeepSeek 配置未改动。

- 四种完整格式的前后对照确认创建、提示词和验证集传递及归一化恢复，原输入不变。
- 最终从实际创建 API 提交 12 条混合格式记录，经真实配置组装、真实 datasets 读取和真实训练标签构建，固定为 **10 条训练、2 条验证**。当前问题、额外输入、历史和人物提示词都保留；只有助手内容进入监督标签，用户及系统内容不参与。

## 范围

原有数据过滤与无效样本计数、数据集重名行为及系统提示词策略保留。风格统计现在消费共享的已验证消息；Alpaca 以前未被训练端消费的历史也会完整进入模型上下文和相应助手监督。

旧 `style_config` 选择仍未定义实际的数据变换，本阶段没有猜测如何应用其数值字段，也不宣称已实现该旧选项。训练配置的其他未实现模式需另行审查，不能把准备链路通过理解为所有训练功能均已验收。
