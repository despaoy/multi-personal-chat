# 输出上限违反时明确失败（2026-10-13）

CitationValidator 原先把超过 max_citations 的合法引用截断，正文超过 answer_max_chars 仅产生告警，仍可返回成功。现两种确定性上限违反均抛 RuntimeError，经已有错误出口终止。保留启发式信号作为告警，不把不可靠语义判断当硬性规则。生产代码净减少 1 行。

服务器 12 项定向测试通过（0.39 秒）：流式/非流式、显示/隐藏引用，以及引用超限、正文超限、恰好达上限三个场景；失败时无成功完成事件，正常边界保留答案与对应引用。完整合成资料，无模型费用、无全量回归。语法和差异检查通过，无新增静态问题。

用户要求持续推进至剩余额度 20% 时停止，执行中按阶段读取账户额度，达到阈值暂停目标。此阶段不宣称全项目错误处理清理完成。
