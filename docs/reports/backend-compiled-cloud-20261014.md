## 缓存来源与范围

聊天回复缓存原先始终使用 vLLM 模型名，云端模型变化可能复用错误来源的回复。现在绑定所选提供商状态、地址与凭据摘要，并增加本次生成契约版本；历史不兼容缓存不能按旧身份命中。生成响应增加 modelInvoked 字段，实际调用按结果赋值，缓存命中为 false 且带 cached_model_response，计时为本次读取时间。无模型正常结果、安全策略和默认幂等结果保持 false，不冒充新的模型验证。

聊天回复缓存限于无检索、无角色上下文、无附加 LoRA 的直接回答；角色和检索链路执行当前证据流程，避免整个回复缓存跳过记忆/关系回写或索引核对。检索与独立知识问答已有缓存保留。本阶段不提供配置更新与完整请求之间的跨系统原子事务保证。

None 是合法未命中，空对象及缺失回复的对象是结构故障；先解析完整缓存响应，再保存消息。读取/解析失败直接报错，不转而重新调用模型。写入失败返回 response_cache 阶段及真实 modelInvoked/messageSaved 部分结果。缓存命中时检查消息保存结果，失败返回 message_archive，不伪装成功，也不追加模型调用。正常未命中、成功复用与来源变化后的重新生成仍保留。
