# 纠正检索关键词改写规则单一实现（2026-10-09）

通用 CorrectiveRAG 与结构化 CorrectiveRetrievalAdapter 复制了完全相同的停用词表、词去重、原问题排除及追加上限逻辑。结构化版本还独自维护 jieba 可用性状态及正则备用分词。现把关键词追加规则集中在 query_reformulation.append_retrieval_keywords，复用必需的 segment，删除两份复制算法和额外回退状态。

适配器各自负责材料选择：通用链路仍读取前三条的标题/正文，结构化链路仍读取前三条的标题/摘要。保留原问题、候选顺序、停用词、大小写排除与最多五个追加关键词规则；不合并两种 bundle，不更改重试与证据合并流程。

服务器 9 项定向测试通过（3.48 秒）：两个实际改写入口的正常结果及不改输入、缺依赖、分词异常；既有中文分词、重复词不追加、两次改写来源与过滤范围检查继续通过。四条警告来自既有 jieba。无全量回归、付费模型或历史数据变更。
