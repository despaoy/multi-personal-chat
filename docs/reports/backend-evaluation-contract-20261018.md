# 评测与检索组件边界整理

日期：2026-10-18。基线：`ba30fee`。

## 实际问题与修改

离线回复比较器使用空记忆仓库比较回复策略，却会继承服务器的来源检索开关。完整复现表明：规则组在生成前因缺少来源接口失败，另外两组按测试设定因非法语义状态失败，三个组均未进入回复生成。

比较器现在明确关闭其输入范围之外的来源检索，并在报告中写入 `source_recall_enabled: false`。生产代码只增加两行，没有创建空来源接口或吞掉异常。正常后端的检索配置与调用链未修改。

相关测试同步整理：

- FAISS、BM25 和范围缓存测试在编码器适配边界提供明确向量控制，停止使用过期的原生模型 `.encode` 替身；索引、搜索、过滤和缓存仍执行真实组件。
- 身份绑定的接口测试提供完整的公共查询规划与已审核传输控制。
- 错误的候选编号明确报错，合法的“主体不符”结果才返回空选择。
- 索引发布失败检查原始异常对象，保留 503、生成前停止、缓存为空和索引未完成的断言。
- 启动失败测试补齐容器已声明的扫描任务资源，继续要求缺少必要配置时在数据库初始化前报错。
- 要求成功的公开角色评测提供完整合法的语义状态。非法语义状态、生成失败、无评审信息泄漏和无固定回复替代的测试继续保留。

## 验证与限制

74 个不同的定向用例最终通过；后续只重测修改的公开角色评测用例，没有重跑全部回归。静态检查、差异检查通过。完成 14 条旧失败记录核对，剩余 41 条待审。

这些是明确控制输入的组件测试，不是模型理解质量评估。真实 HTTP 传输被阻止，没有新增付费模型调用。本阶段无需重启后端；就绪接口与前端登录仍为 200。

仍有三条真实 CPU 训练集成测试需要 `backend/requirements-preference.txt` 指定的独立环境，后续单独处理。整体优化及最终整体验收未完成。
