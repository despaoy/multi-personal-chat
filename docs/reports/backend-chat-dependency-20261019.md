# Web 聊天依赖归属

基线：`583264ebaa8e30e5c4974d3a02f7fce5d45c7b24`。沿 Web 认证、服务工厂、队列准入、执行时提供方解析、角色上下文及消息存储检查实际调用链。

## 问题与修改

聊天工厂在容器调度器为空时自动选择全局调度器；数据库为空则把空值传入共享核心，由历史兼容入口选择全局数据库。真实 HTTP/SQLite 对照证实：缺数据库仍返回成功并写入另一数据库，缺调度器仍使用另一队列。

工厂现在直接绑定容器调度器。必需数据库或调度器缺失时，在准入前返回 503，附依赖环节及启动配置提示。使用一个入口检查替代隐式回退，生产代码净增加 4 行，没有增加新层、重试、模型切换或语义规则。默认配置继续复用默认服务，自定义及合法假值实例保持身份。共享核心的显式非 HTTP 兼容入口、生成和记忆逻辑未改动。
