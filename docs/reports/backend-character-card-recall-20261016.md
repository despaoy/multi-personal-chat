# 角色知识卡片统一召回与明确索引失败

## 问题和修改

卡片检索原先按身份、关系和事件关键词选择子索引。完整的三项问题可能只召回关系卡片，导致后续模型无法获得身份与事件证据。必需的故事索引缺失时，还会改查卡片索引，返回与声明检索类型不一致的结果。

本阶段删除卡片类型选择器及其三组关键词表。普通卡片检索统一召回事实、关系、事件，再执行现有权限、归属和排序处理。删除缺失索引时的替代检索：必需索引缺失直接抛错；合法空索引返回无匹配，不调用向量模型。保留空向量矩阵的声明维度，使其能通过正常就绪检查。

运行时检索索引从九组重叠副本精简为两组：统一卡片索引和现有故事／场景索引。证据文档仍用于原文关联，未删除任何源数据。关系时间线继续按关系文档、人物、可见性和归属过滤。生产代码新增 19 行、删除 55 行，净减少 36 行；未新增依赖、配置或意图规则。

## 验证

- 修改前使用完整虚构资料确认：三种卡片分别可检索并读取原文；组合问题漏掉事实与事件；缺失故事索引会改查卡片。
- 服务器定向检查共 50 个不同用例通过，覆盖组合问题、别名、原文、权限、时间线、上下文预算、来源生命周期、缺失索引和合法空索引。未运行全量回归。首次四项失败来自缺失部署模型路径及过期读取替身，补齐前提后仅重跑失败项与新增项。
- 迁移涉及的其余 217 条原有业务断言经 AST 对照保持一致；只退休三项专门验证旧类型分区或回退行为的测试，另更新一个路由诊断预期、移除一个已删除选择器的断言。
- 使用服务器真实本地向量模型、矩阵向量检索、BM25 和现有启发式排序，进行一次 `deepseek-flash` 回答抽查，无额外语义审核请求。完整身份、非亲属关系、争执原因和后续处理均有回答，返回三条引用。未启用交叉编码重排；小型虚构语料不代表全域检索准确率。
- 无新增静态检查问题，差异格式检查通过。服务器重启后后端就绪与前端登录页均返回 200，配置及其他服务未变。

## 后续边界

本阶段未移除故事／场景选择中的旧概述关键词，也未替换旧软排序偏好及身份、人物对范围识别。整体优化目标仍然进行，后续应沿实际服务链路逐步替换这些判断，不能声称本阶段已清除所有意图规则。真实回答还带出了内部来源范围标记，可在后续提示与输出链路清理中处理。
