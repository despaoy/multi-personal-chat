# 本地模型精度和适配器生命周期明确失败

日期：2026-10-16。基线：`106c63ffaa4d80be035f433fbbbce1bcd9f9a89a`。

## 已复现的问题

在服务器真实 TransformersPeftProvider 与合成 ML 构造边界中，NF4 首次加载失败会改用另一精度并返回成功；清除 LoRA 只清元数据，下一次实际生成仍使用旧适配器；eval 失败留下模型引用，后续生成跳过初始化。

## 修改

保留现有首选 NF4 加载方法，删除自动 8-bit/FP16 后备方法及宽泛捕获，原始加载异常直接传播。tokenizer、base、可选 LoRA 和 eval 全部成功后才发布可用状态；缺失的显式适配器目录在选择和冷加载时明确报错。

选择未变化时复用现有模型。选择改变时清空模型、tokenizer 和 loaded 状态，下次生成从干净 base 完整加载，避免任意 PEFT 适配器对 base 权重的修改残留；不依赖无法对所有 adapter 配置保证恢复原权重的热卸载。代价是切换时需要重新加载模型。close 先清状态，GPU 缓存释放错误不再被日志捕获掩盖。

生产代码净减少 54 行。当前运行的 DeepSeek 提供商及其配置不变，没有新增精度配置、算法或回退。
