# 查询分词统一与隐式回退删除（2026-10-09）

确定性重排与纠正性 RAG 正常情况下都使用 jieba 分词、strip 并去空项，却分别在依赖缺失时改用正则，改变词覆盖与查询改写行为。现在共用 retrieval_core.tokenization.segment，缺失依赖或分词失败直接上报。删除 CorrectiveRAG 的 _JIEBA_AVAILABLE 状态、旧 _tokenize 入口及两处正则回退。不修改 BM25 特有的词元组合规则，重排停用词/实体排除及纠正检索关键词约束仍在各自业务层。

过期测试不再要求依赖缺失时改用备用算法，替换为两个真实调用入口的成功和失败行为检查。既有中文分词检查不再以缺失依赖为理由跳过；重复关键词与无需二次检索检查保留。

服务器 9 项定向测试通过（3.53 秒），包括真实中文候选排序与输入不变、完整合成证据的纠正检索、两个入口分别缺少依赖和分词异常，以及三项相关既有检查。四条警告来自既有 jieba 依赖。无全量回归、无付费模型，不改变已配置的重排方式。
