# 正史生成不再回退全局调度器

正史入口原先通过 `container.inference_runtime or inference_runtime` 选择调度器。应用依赖缺失时会静默使用全局实例，布尔值为假的有效实例也会被替换，与普通聊天入口的容器归属约定不一致。

删除全局调度器导入与回退，只使用容器指定实例。数据库或调度器为 `None` 时，在入队和模型调用前返回带 `dependencies` 阶段的 503，采用普通聊天入口已有的错误语义。没有新增包装或模块，生产代码净增加 4 行。

验证结果：

- 将既有完整正史与分支生成测试中的调度器设为布尔值为假，验证该实例仍被使用，历史隔离及回写断言保持通过。
- 新增两个缺失依赖场景，分别验证无数据库、无调度器时明确报错，并禁止调用全局调度器或模型。
- 分支业务及应用工厂两个文件共 47 项测试全部通过，无跳过；静态、仓库完整性及差异检查通过。
- 后端重启后就绪与前端登录返回 200，未登录受保护接口返回 401；配置及前端进程未变化。
- 服务器验证后按内容哈希同步本地。

未调用真实大模型，未重复运行全部回归测试。本阶段只调整正史入口的依赖选择，不改变队列策略及分支业务语义。
