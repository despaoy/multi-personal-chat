# 正史复用统一上下文准备入口

正史入口原先自行创建 `TurnInput` 并直接调用 `prepare_turn`，与普通聊天的输入映射、上下文错误转换分离。预算不足等已知错误无法获得普通聊天已有的明确阶段信息。

改为先构造完整 `MessageRequest`，再调用既有 `_prepare_character_turn`。删除重复的 `TurnInput` 组装和导入，保留默认不执行交互记忆操作的语义。模型连接仍在准备之前确定，准备结果仍由生成入口直接复用。生产代码净减少 1 行，无新增错误包装层或规则。

扩展已有正史请求测试，验证平台、适配器、用户、会话类型与 ID、空现场历史及接收时间保持一致。普通准备错误返回 503 并保留异常原因；记忆证据预算不足返回 `memory_context / selected_evidence_budget_exceeded`，内部错误原文不进入响应，失败后不调用生成。

服务器上分支业务和聊天服务两个文件共 49 项测试全部通过，无跳过。静态、仓库完整性及差异检查通过。后端重启后就绪与前端登录返回 200，未登录受保护接口返回 401；配置和前端进程不变。验证后按内容哈希同步本地。

未调用真实大模型，未重复运行全部回归测试。本阶段复用现有 API 内部入口，未宣称整个生成模块已完成分层。
