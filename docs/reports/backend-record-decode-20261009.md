## 问题与修改

仓储 JSON 解码原先把解析异常替换为空容器，之后三个字段又各自检查类型并再次替换为空。损坏证据/来源/元数据因此可被当作有效空记录。关系记录的未知阶段也被静默变成 stranger。

- 合并 JSON 解析和容器类型校验，按字段要求 list/dict；非法 JSON、空字符串、错误容器类型以及 JSON null/数值/字符串明确抛错。
- 缺失字段或数据库 NULL 保留空容器含义；合法 []/{} 和旧单一 source_message_id 合并行为保持原样。
- 未知关系阶段明确报错；确实没有关系记录仍返回默认陌生关系。
- 错误消息仅指出字段名或预期类型，不包含原始值。未知关系阶段值也不回显。
