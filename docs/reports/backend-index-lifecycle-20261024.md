# 索引生命周期从 API 层迁出

日期：2026-10-24。基线：`2cfa5e04a823b8eaf05ef5e98ccc82cb9d0eb5f7`。

## 职责调整

通用知识索引的重建、指纹、数据库版本、发布锁和本地所有者状态原来全部位于 `api/knowledge.py`，生成入口还需反向引用该 API 模块来获取索引状态。

将九个生命周期函数及其状态整体迁入 `knowledge/index_lifecycle.py`。知识 API 负责请求与响应，调用索引模块完成失效和重建；生成入口直接调用索引模块读取版本、建立索引和核对来源时效。未保留旧 API 名称的转发函数或复制状态，也未增加管理器框架。

调用方、评测入口与隔离测试同步迁移到新所有者。测试中的数据库替换同时绑定 API 与索引模块，手动恢复场景分别保存和恢复两个原始绑定。原断言及失败条件保留。

这次是职责收敛，不是删除索引一致性机制。九个函数迁移前后的 AST 完全相同；保留修订号 CAS、落盘后发布、同数量内容变化检测、空库清理、并发更新失效及异常传播。非测试 Python 文件合计增加 26 行，主要来自独立模块声明及调用方导入。

## 验证

先在服务器修改，验证后部署，再同步本地。

- 定向选择 34 个测试文件，覆盖索引重建、数据库与向量实例替换、事务、知识 CRUD、导入部分完成、公共证据核验及相关生成调用。
- 首轮 521 项中 36 项失败，原因是迁移遗漏测试模块导入或多行替换目标；补齐绑定后仅重测受影响的 12 个文件，共 238 项全部通过。合并逐项结果后，521 个唯一用例全部通过、无跳过。
- 修改文件通过未使用导入、未定义名称及重复定义检查；仓库完整性、差异检查通过。九个函数的 AST 对比通过。
- 部署后后端就绪及前端登录页面返回 200，未认证受保护接口返回 401，安全响应头存在；配置及前端进程未改变。

本阶段没有运行全套回归或真实模型。评测脚本完成引用迁移与静态检查，未重新执行其中的真实模型实验。

## 保留的边界

通用知识库仍是进程级共享资源，默认应用容器、知识 API 与索引模块使用同一数据库适配器。此次没有实现多应用数据库隔离，也没有把通用知识库切换到调用者注入的私有消息库；公共原文读取和最终证据核验保持同源。
