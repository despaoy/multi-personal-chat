# 记忆有效期错误契约（2026-10-09）

## 修改

模型日期解析失败、起止时间倒置原先返回 None，提案被静默丢弃；0、False、空列表等还会被 or 链当成未提供时间。

现在非法结构、非法 ISO 日期及倒置区间抛出带规范字段名的 ValueError。日期选择只跳过原本允许的 None 和空字符串，不再把其他假值视为空。移除 None 错误哨兵及对应重复判断。

保持顶层字段、旧别名、历史 qualifiers 时间位置的现有优先级；可选时间为空仍可解析。日期精度原值、时区规范化和服务器观察时间权威保持原有处理；模型 observed_at 仍不能替代服务器来源时间。

## 验证

64 项相关测试最终通过。首轮 62 passed，两项旧测试仍期望非法日期/倒置区间返回空列表；随契约更改为要求字段异常后，仅重跑这两项，2 passed（0.38 秒）。原错误输入和拒绝要求保留，没有通过放宽检查获得成功。

覆盖六种错误值与四个顶层字段/别名、正常空时间、旧时间位置兼容、模糊时间来源、日期精度和服务器观察时间等直接关联路径。未运行全量回归；本阶段没有模型调用，格式与区间判断为确定性检查。

不声称所有自然语言时间已能可靠解析；合法但来源证据不足仍依既有规则拒绝。部署、代码规范与同版本同步记录位于服务器本阶段备份目录。
