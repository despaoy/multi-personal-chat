# 原作读取故障不再伪装成证据失效

日期：2026-10-16。基线：`c3d54ab13bfa7ae43f42bfe5b34d569a05f3285c`。

## 问题与修复

主聊天编译回答时，`exclude_changed_sources` 和 `render_curated_tasks` 会再次验证审核时读取的原作快照。这两处此前将全部 OSError 与来源内容变化一起处理，移除出错原文，标记 `source_changed_since_review` 后继续生成。

服务器隔离预检在完整双来源原文、问题绑定及审核回执建立后，令第一份现有原文的实际 `Path.read_bytes` 抛出 PermissionError。结果编译仍成功，丢掉权限拒绝的来源，仅保留第二份原文。它掩盖了依赖读取故障，并不能说明原文事实已失效。

本阶段仅收窄两处异常捕获：保留 `CuratedSourceChangedError` 和 `FileNotFoundError` 的既有局部证据撤回语义，PermissionError 及其他 OSError 原样传播。未增加检查层、分类规则、依赖、重试或替代答案。正常原文更新和明确删除后，仍撤回过期证据并保留其他有效来源；不会把旧审核摘要继续注入模型。

## 验证

服务器 15 项直接相关测试通过（0.86 秒）。新增 7 项复用真实原文文件、完整来源目录、问题绑定、审核解析、证据预算和生成入口：

- 渲染、撤回两个入口分别遇到权限错误与磁盘 I/O 故障时，均保留原异常对象，不能转成空结果或过期资料。
- 实际生成主链两种 I/O 失败均在模型调用前终止。
- 健康路径仍将完整原文、归属和限制送入实际提示词；原文件与回执均保持不变。
