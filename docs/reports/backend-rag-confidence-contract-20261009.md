# RAG 置信度源分数的明确失败（2026-10-09）

RAGHelper._absolute_score 原来将无法转换的分数和缺失字段返回为 0；非有限值直接进入 min/max，NaN 与正无穷可能成为 1。retrieve_with_citations、任务候选覆盖及来源范围收窄共用 compute_confidence，错误分数因而可能伪装成正常弃答或足够证据。

现在缺失、不可转换、布尔值与非有限分数明确抛出 ValueError，错误信息标识 RAG 检索分数。保留 score、fused_score、final_score 的优先级和有限值截断规则，不改置信度加权、不增加备用分数；高优先级字段存在但非法时不能改用下一字段。

服务器 15 项定向测试通过（2.59 秒）：七种非法结果经过实际引用/弃答入口均报错；五种合法分数验证字段优先级、上下界与置信度决策；空结果保持正常弃答；两项既有绝对分数与知识库过滤检查继续通过。使用完整合成证据，不调用模型，无全量回归。

该检查覆盖参与置信度计算的前三级结果，不新增全结果扫描，也不声称数值合法便能证明证据语义充分。语义充分性仍由既有证据链处理。
