# 删除查询意图猜测与重复排序加权

## 修改

旧查询分析器把“经过”归为事件偏好，并继续推断身份、因果、叙事层和关系类型；这些标签在召回与重排中重复加权。“概括《翡翠的排斥原理》的经过”因此只排出了事件卡片。长原文还受到额外长度扣分。

本阶段删除十个派生查询字段、无调用方的过滤建议、手工同义词扩展、类型乘数，以及身份、因果、关系类别和叙事意图加分。删除完整长来源的长度扣分。来源依赖与任务规划继续由现有 DeepSeek 语义流程处理；查询分析仅提供原始文本、登记别名、实体、故事名和域匹配信息。原始输入的首尾空白与换行也完整保留。

保留明确调用参数中的元数据过滤、配置声明的叙事层策略、登记对象匹配、原文读取和权限／归属校验。显式启用模型重排时，模型故障仍直接抛出，原始分数、顺序和来源保持不变。没有新增分类器、依赖、模型调用环节或配置项。

来源片段的范围说明改用中文，避免提示把 `complete_declared_span` 等内部枚举抄入回答。只替换两个显示字符串，AST 对照确认其余逻辑和原文拼接不变。生产代码新增 35 行、删除 293 行，净减少 258 行。

- 修改前用内容完全相同的完整证据视图复现：旧标签会额外提高事件类视图的名次；长完整来源会被扣分。显式过滤对照正常，测试具备完整输入。
- 70 个直接相关的定向用例通过，包含排序、别名、原文保留、显式过滤、归属、模型结果校验、模型失败行为和来源投影／缓存。未运行全量回归，已通过用例未反复重测。
- 保留迁移文件内其余 102 条原有 `assert` 语句。退休一个仅检查旧意图标签的测试，移除一个检查无消费方扩展字段的断言子句；核心原文、对象范围和错误断言没有放宽。
- 同一真实语料与本地向量模型抽查三条查询：新概述表述已返回场景资料，原有“完整回顾”仍包含故事／场景资料，关系查询将两条直接关系资料排在前面。所有被选资料均有完整原文凭据。这里只确认事件类型偏置解除，不代表整卷覆盖已经充分。
- 十份完整虚构记录上的三组原手工同义表达检查通过：真实向量首项命中对应记录，混合召回前三项保留完整目标内容；没有手工改写、回答生成或新文件原文核验。这项结果仅证明这些候选召回案例。
- 一次 `deepseek-flash` 真实回答抽查覆盖概述、身份、非亲属关系、争执原因和处理结果，实际引用完整场景及相关来源。该调用发生在中文范围说明清理之前；清理之后只补跑两项原文投影／缓存检查，没有再次付费验证模型措辞，也没有把旧输出标成新模型结果。
- 无新增静态检查问题，差异格式检查通过。服务器重启后后端就绪和前端登录页均为 200，配置及其他服务未变。

## 仍需推进

单字别名的自动域门控仍使用旧问法提示词；身份和人物对范围识别还存在旧模式判断。本阶段不能声称全部规则已移除。后续应核对语义对象绑定与显式域入口，减少重复扫描和隐式域选择。

真实概述候选仍可能包含其他卷的回顾资料；来源适用性、整卷事实覆盖以及长原文进入模型的预算尚未完成本阶段语义核验。整体目标继续进行。密钥、运行数据、实际原文和原始模型交换记录不提交。
