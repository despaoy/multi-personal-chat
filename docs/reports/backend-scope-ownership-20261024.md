# 用户范围模型的职责归属

## 问题与修改

历史来源授权等模块仅需要规范化用户范围，却依赖上下文编译模块中的 `build_user_scope`，使基础数据处理反向依赖生成上下文。

将该函数移至 `character.models`，与 `UserScope` 同处一处，迁移全部已跟踪 Python 调用方的导入。删除旧位置实现及无用导入，不保留转发接口，不增加校验、回退或新抽象。共调整 34 个文件，非测试代码净减少 7 行。

函数移动前后的语法树完全一致，平台、适配器、用户标识及会话范围的原有规范化与校验行为保持不变。
