# 记忆向量缓存容量与批次发布（2026-10-09）

长期存活的 CharacterMemoryService 原先无限保留 ID/更新时间/内容哈希组合的向量，旧版本会持续积累；批次逐条归一化时又立即写入缓存，后面一条失败也留下前面部分结果。改为最多 1024 条的最近使用缓存，在完整归一化和评分成功后才统一发布本批向量，复用已有锁，无新增配置。

缓存按同一服务编码器及记录版本/内容使用，实例销毁即清空，不缓存查询答案。淘汰只影响下一次是否重新编码，不裁剪本次候选或改变召回结果。失败批次不更新缓存内容或最近使用顺序。
