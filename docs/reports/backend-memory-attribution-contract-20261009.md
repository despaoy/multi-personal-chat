# 用户事实必须明确给出归属（2026-10-09）

## 问题与修改

记忆模型提示明确要求 `attributed_to=user`，但 `_normalize_attributed_to` 曾把缺失、null、空字符串、false 和零都默认归为用户。现在用户事实归属必须是非空字符串，否则抛出含字段名的 ValueError；不再把结构缺失伪装为正确归属。保留明确的 user/self/用户/本人标签和其他主体不写为用户事实的业务拒绝。

业务代码增加 2 行。只补齐 6 个测试文件中 13 个合成输入缺少的归属字段，原业务断言保持；未修改历史模型原文或冻结评测记录。共享事件的既有观察主体规则不在本阶段修改范围。
