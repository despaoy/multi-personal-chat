沿知识写入、导入工具、原生向量与 BM25 检索、来源扩展、引用及消融评测核对，确认文档契约要求 `id`、`title`、`content`。旧实现却能给缺少标题或正文的文档生成向量并落盘，再用空身份、旧别名、未知标题或空正文构建引用。合法的关键词独有命中只有 `fused_score` 时，引用分数还被填为零，与既有置信度不符。
