# 复用已经校验的私有来源包

本地基线：`3c32966265d5b5b898a2cd9cabf285ff4fa6c7f7`。

## 问题与修改

私有来源重新授权先解析 JSON 校验完整格式，再解析一次取得记录；部分来源撤销后，重建剩余包还要再次解析原始字符串。同一来源包在一次校验中最多重复解析三次。

完整性校验现在返回已校验对象，两个调用方仍对无效结果立即抛出原有错误。私有来源校验复用该对象读取及重建记录，保留未改变时的原始字符串；部分保留通过新字典和新记录列表构造结果，不修改输入对象。

闭合字段、来源身份、说话者、未知主体和当前有效性、非空原文、唯一 ID、带时区时间均按原规则检查。重新读取授权、冲突来源检查、撤销后的历史清理及预算准入继续独立执行。没有跨发送缓存、异常转空结果或新增模型调用。

## 定向验证

隔离完整输入测量：两个完整合成来源中一个撤销，实际授权读取仍为一次，另一个完整保留；原始来源包未改变。同一输入字符串的 JSON 解析从基线 3 次降至 1 次。这是处理次数控制，不是模型质量评测。

12 项不同相关用例通过：完整授权原话保留、撤销后独立原话及公共证据保留、两个位置的坏包阻止生成、读取异常在生成前后均明确失败、四类坏候选拒绝、完整长来源准入、预算不足时拒绝且保留原输入。

其中 11 项直接在隔离本地环境通过。另一个已有 API 组件控制缺少测试前提，先因模型配置发现依赖、随后因无 embedding 权重而失败；仅为该受控用例显式提供请求上下文（65536 工作窗口、通用计数）及已被测试替换为空检索时的固定超时，再单独重测通过。没有安装模型、改动生产初始化或修改断言；不将该组件控制计作原生模型、向量或真实检索验证。

修改的两个生产文件 Ruff 和补丁空白检查通过。没有新增只检查内部实现的常驻测试，未重复执行已经通过的其他检查或全量回归。无付费请求、运行数据变更和服务器部署；服务器同步待连接恢复。
