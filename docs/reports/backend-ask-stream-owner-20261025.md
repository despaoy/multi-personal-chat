# 独立问答直接管理上游流

整体核对独立问答的提供商适配、SSE、证据校验和取消路径时，发现流转发存在多层所有权：外层返回流再遍历内部生成器，内部生成器才负责关闭真实上游。受控复现先读取一段再关闭外层，外层已结束，上游却没有立即关闭，需要等待内部生成器后续清理。

## 修改

适配器现在直接持有实际 vLLM 客户端返回的流，并在自身退出时关闭它。惰性初始化只缓存真实客户端，不再缓存转发函数组合；必要的并发初始化锁保留。

当前云端路径提供一次性完整生成，不再额外构造一层一次性结果转流的生成器；已有问答服务统一完成 SSE 适配。服务原本就会收集并完整验证回答后再返回正文，这一来源与引用约束保持不变，没有引入模型切换、局部成功或未经校验的提前输出。业务代码净减少 16 行，没有新增配置或异常包装。

客户端断开的说明同时收敛为取消本地等待、关闭已打开的上游流，不承诺远端模型服务一定停止其内部计算。

## 验证

- 同一受控场景修改前为“外层已关闭，上游未立即关闭”，修改后为两者均关闭；修改后结果绑定当前源码哈希。没有真实网络或模型调用。
- 九个相关文件共 236 项检查通过；核对所有私有适配调用方后，只补测最后一个模型归属文件，7 项通过。合计 243 个不同案例通过，无跳过，没有重复全部回归。
- 四项新增行为用例覆盖提前关闭、正常完成、上游报错及取消；均在返回前关闭上游一次，原错误及取消继续传播。客户端仍按需初始化，完整消息、参数和原请求模型归属保留。
- 云端来源、引用、缓存、HTTP/SSE 错误及默认提供商中途切换的既有断言通过。更新直接依赖旧私有返回形式的测试，改由实际问答服务适配一次性结果；未放宽模型归属、调用次数或原文断言。
- 静态、语法、仓库完整性、源码哈希和差异检查通过。部署后就绪及登录页返回 200，未登录受保护接口返回 401，安全响应头存在；配置及前端进程保持一致。最后补测只修改测试文件，没有再次重启业务进程。最终文件按哈希同步本地。

本轮未调用付费模型，也未连接真实 GPU 推理服务；关闭行为使用受控异步上游验证。没有宣称改善云端首字延迟或远端计费停止时间。独立问答及后台模型调用的完整用量统计仍属其他待办，不因本次清理视为完成。
