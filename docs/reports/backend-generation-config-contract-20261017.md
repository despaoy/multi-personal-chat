# 设置写入与推理共用数值契约

基线：`a27dcabfe1753cdd9383eaea6d6510430c7f196e`。

## 问题与修改

设置接口原先只验证配置值的字符串形式。隔离复现确认：无效温度可被保存并返回成功，直到生成时才报错；数值字段 `maxTokens="****"` 还会被当作未修改的凭据占位值而静默忽略。

将现有生成数值模型及读取函数移到纯模块 `backend/inference/generation_options.py`，由设置、生成入口、缓存身份和检索生成共同使用，删除生成 API 内原实现。温度有限且非负、输出长度为正整数、`topP` 在 `(0, 1]`，布尔值不能充当数值；原约束保留。通用缺省值只定义在模型内，读取函数明确按配置、环境变量、模型缺省的顺序解析。

设置补丁在持久化及凭据占位过滤前验证本次提交的三个已知数值字段。无效值返回 422，指出字段，保留异常原因而不返回原值。合法数值字符串按同一契约转换后保存；未提交字段不补默认值，也不读取或重新验证其他旧设置及环境变量。这样既能逐项修正旧错误，又不会让错误数值被当作凭据占位值忽略。凭据保护、管理员鉴权及设置部分完成状态未改变。

业务源码增加 52 行、删除 27 行，净增 25 行，无新依赖、意图规则或分类器。共享模块包含实际参数契约及优先级解析，未保留旧私有函数别名或另增转发层。
