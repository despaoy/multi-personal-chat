## 问题与修改

关键词索引尚未构建、向量索引缺失或向量行数不足时，旧检索接口可能返回空结果或继续给出部分通道结果。健康检查只看文档清单数量，也可能把这种状态标成健康。未知模式则自动进入混合检索。

- 查询按所选模式要求索引就绪，向量和关键词行数须与文档一致。缺失及数量不一致使用同一具体异常报告，不改变检索模式。
- 健康检查使用相同就绪条件；已完成构建的空关键词索引与“尚未构建”明确区分。明确初始化的空索引、实际无匹配及请求零条结果仍可正常返回空结果。
- 显式关键词模式不要求向量通道，显式向量模式不要求关键词通道。未知模式直接失败。
- API 返回 503，包含 `retrieval_index` 环节、通道、`not_initialized` 或 `row_count_mismatch` 原因及恢复方式，不暴露原始问题或文档内容。
- 在数量条件闭合后删除不再可达的空邻居判断；非空通道直接计算实际最大分数，移除无意义默认值。

没有添加替代模型、替代索引、自动重试、意图规则或运行依赖。
