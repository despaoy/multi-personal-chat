# 简化意图决策并传播预测错误（2026-10-14）

## 问题与修改

实际聊天链路在来源依赖判断后调用 needs_rag，再进入查询规划和检索。原意图决策按置信度 0.65 分为高低两组，再检查模型/规则是否一致或冲突；逐项核对后，其检索布尔值始终等价于模型正例或规则正例，知识库选择只来自模型正例。低置信度模型正例仍会重复调用规则，预测异常还会被捕获后替换为规则结果。

现在先保留原有私人任务边界，再在已加载分类器预测为正例时直接返回其路由；其他有效情况使用共享规则。删除重复的高低置信度、一致/冲突分支及预测异常吞掉。已加载分类器预测失败时原异常向上传播，聊天入口统一返回 HTTP 503，在查询规划、检索与回答前停止。可选分类器未加载的原有规则路径保留。

诊断原因统一来自实际决定本次路由的分支，不再拼接“规则一致”等装饰文本。清理确认无调用方的 _contains_genshin_content 旧兼容方法，以及模块内旧题材的手动打印演示；有效测试保留并转为定向自动验证。生产代码净减少 98 行，没有新增依赖、配置或策略层。
