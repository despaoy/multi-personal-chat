# 记忆检索特征复用

完成日期：2026-10-24。基线：560fd52。

## 问题与修改

`CharacterMemoryService.load_relevant_memories` 对多个查询视图进行词法评分时，重复构建同一记忆内容与事件主题的二元字符集合。现在每条记忆只构建一次，交给纯评分函数复用；Jaccard 分母直接通过集合大小与交集大小计算，移除重复构建、并集分配及冗余空集判断。

仅修改一个生产文件，净减少 4 行。没有新增缓存、配置、语义规则、回退或模型调用。空查询仍不构建特征；检索范围、证据、时间约束、生命周期及后续排序逻辑保持原样。
