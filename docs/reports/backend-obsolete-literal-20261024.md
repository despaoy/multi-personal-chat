# 删除过期的原话定位解析器

## 依据与修改

全仓库已跟踪 Python 源码中，`literal_source_fragments` 只有自身定义和两个测试文件中的引用，没有业务调用方。实际检索由 `search_plan` 调用 `resolve_source_read_plan`，统一解析单项、组合及跨领域读取依赖。

旧函数仍保留另一套语义：把“和／或”组合读取视作未解析请求；现用读取计划已经支持这些操作，并有同条记录交集及不同记录并集的行为测试。因此保留旧函数及其专用测试会同时维护两套不一致的契约。

删除旧函数和四个仅调用它的测试函数，保留两个文件中的数据库与服务集成测试。生产代码减少 36 行，消除 `db.memory_source_search` 对 `character.quoted_erasure_authority` 的无用依赖；没有增加解析规则、转发接口、回退或默认值。

删除前后逐文件比较语法树，确认除指定五个函数外，其余实现和测试均未改变。
