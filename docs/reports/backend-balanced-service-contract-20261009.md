# 平衡版评测使用明确的服务契约（2026-10-09）

原评测通过 inspect.signature 过滤构造参数，并在历史查询参数缺失时静默省略它。这样旧服务也可能以改变后的条件继续生成实验结果。现在直接传入全部实验参数和 include_historical，不支持构造参数时明确失败，删除两处签名探测和冗余参数过滤。

修复平衡版实验仓库缺少 include_inactive 关键字参数的问题。该适配器有意保留全部合成记录状态，供服务层生命周期消融比较使用；它不冒充生产数据库的 active 筛选。基础评测与这个消融适配器用途不同，因此没有为了减少文件而强行合并。

保持既有报告字段：unsupported_service_switches 为空、historical_query_control_supported 为 true，当前接口是必要前提。逐例检索异常仍记录具体 error 和失败条目，不增加 successfully_processed_cases。

服务器四项定向测试通过（0.58 秒）：完整偏好记录在当前/历史两种请求中经真实服务成功召回，历史参数实际传到仓库；存储异常明确计为失败；不支持实验参数的旧服务在构造时抛出 TypeError。静态检查无新增问题，生产代码净减少九行。

没有运行全部旧评测测试或完整 Gold 数据集；未声称完整平衡版评测及所有旧夹具已达标。使用显式嵌入替身，无付费模型调用。本阶段不调整实际记忆语义或生产数据。
