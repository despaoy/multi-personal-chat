# 主聊天保留任务对象与登记称呼

主聊天的证据审核原本能看到已验证对象的查询称呼和登记名，但最终 `curated_tasks` 只投影对象编号，丢失了这层对应。本阶段在原有任务投影中保留本任务角色对象的编号、原称呼和登记名，直接复用已校验的语义绑定和域登记，不重新分类或猜测名称。业务对象不会混入角色投影。

回答协议允许使用非空登记名对应理解用户指代，不要求原文再次出现简称；名称对应不能证明别名来历、其他原作事实或访问权限。原有来源新鲜度、原文接纳状态和事实范围均保持独立：名称仍可识别而原文未进入请求时，事实仍为未接纳。生产代码增加七行，没有新增审核、模型调用、配置或依赖。

61 个直接相关的定向用例最终通过，无失败或跳过，覆盖最终提示、任务归属、业务隔离、绑定篡改、原文变更、证据未接纳和引用提示。保留修改文件内全部 65 条既有断言。一组旧错误测试缺少当前运行时的 `is_warm` 状态；已在未改动的 API 检查处复现同样错误，补齐测试前提后只复测六个失败项，原有错误类型、异常身份和禁止生成的断言不变。没有重复全量回归。

本阶段模型调用为零；仅确认登记名称确实进入最终主聊天请求及相关边界，未重新评估真实模型回答质量。独立问答阶段的真实模型结果不计作本阶段新验证。静态检查无新增问题，差异格式检查通过；部署后前后端均为 200，配置与其他服务未变。
