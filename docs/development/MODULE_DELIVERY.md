## 浏览器提醒

迁移 034 为每个会话分别保存浏览器订阅和发送结果。用户开启应用内主动联系后，可选当前浏览器，并通过点击按钮授予浏览器权限。每个会话最多登记五台浏览器。关闭单台浏览器的提醒只删除对应会话的设备登记。关闭会话的主动联系、删除会话或恢复 SQLite 备份会清除相关浏览器登记。重新开启主动联系后，需要逐台重新授权。

正式消息先保存到应用内收件箱，随后后台检查授权与免打扰时段，并对五分钟内的新消息尝试发送通用提醒。推送只传递去重标识，点击打开当前站点的收件箱。短时故障最多尝试三次，失效订阅会清理。已经交给浏览器推送服务的提醒无法由应用撤回。无提醒配置、浏览器拒绝授权或发送失败时，用户仍可从收件箱查看消息。

启用前，需要在 API 和聊天 worker 配置相同的 VAPID 私钥及联系地址，并在 worker 打开 `CHARACTER_CHAT_PROACTIVE_ENABLED`。私钥通过 `CHARACTER_WEB_PUSH_PRIVATE_KEY` 提供，格式为 32 字节 P-256 私有标量的无填充 base64url。联系地址通过 `CHARACTER_WEB_PUSH_SUBJECT` 提供，接受 `mailto:` 或 HTTPS URI。浏览器端需要安全上下文。服务端目前接受 FCM、Mozilla 和 Apple 的推送服务地址。

## 关系阶段如何影响人物表达

网页角色会话现直接复用原有四档熟悉程度的表达规则。初识保持礼貌，避免假定默契或打听私事。熟悉时可在相关场合提起有依据的共同经历，同时尊重用户当下的边界。生成提示只采用已生效的关系，待确认的建议不影响角色表达。

真实 DeepSeek Flash 使用同一合成角色和同一句消息复验两种状态。初识回复直接回答西门铜铃的状态；手动设置为熟悉并添加试敲经历后，回复引用了此前共同试敲。两种回复均遵守“别问我的事”，并从各自会话读回已保存记录。此次对比同时改变了熟悉程度和确认过的经历，无法据此单独量化阶段对语气的影响。

Chrome 使用环回模型替身验证手动保存为熟悉、创建分支继承该状态、替换原会话消息后回到初识，以及分支仍保留原文和熟悉状态。后端 78 项定向测试与变更文件 Ruff 检查通过。多维关系的指标、变化规则和展示方式仍待确认。

## 记忆纠正与共享列表一致性

确认或纠正自动提取的记忆后，已确认的用户版本具有手动来源。生成提示只使用用户确认的记忆正文，避免把旧模型推断和旧证据作为当前记忆重新传入。来源原文仍可在记忆面板核对，普通对话记录按原回退规则独立保留。

纠正、删除或回退造成记忆变更时，后端按原有事务撤销旧共享。网页完成相应操作后同步刷新账号内的共享项和选择，避免创建新会话时仍展示已撤销的旧记忆。已有剧情分支和已复制的会话各自保有快照。
