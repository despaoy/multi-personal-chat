# R1V4 E1 稳定性校准结果

## 当前结论

原 E1 效果差的首要原因不是 vLLM，也不能简单归因于训练数据回答太短，而是 LoRA 容量和作用范围对当前数据规模过大：`r=32` 同时训练 7 个 projection，共有 87,293,952 个可训练参数。即使把学习率降到 `2e-5`、alpha 降到 16，模型仍会在 20 到 40 step 之间从完整回答迅速坍缩为短回答。

低秩注意力方案 `r=8/alpha=8`、学习率 `1e-5`、仅训练 `q/k/v/o` 后，可训练参数降为 7,667,712。全部六个 checkpoint 均通过机械生成门禁，证明短回答和循环的结构性问题已经解决。

`checkpoint-100` 曾暂定为语义盲评候选。后续 30 条 AI 辅助、用户确认的匿名 A/B 审核中，它以 8 胜、18 负、4 平落后 Prompt-only，且严重错误为 13 条，高于 Prompt-only 的 11 条，因此已经拒绝，不是正式 adapter。E2 继续暂停。

## 排除过程

1. 直接 Transformers + PEFT 与真实 vLLM 得到相同短回答，排除了 vLLM 动态 LoRA 加载问题。
2. 学习率从 `1e-4` 降为 `2e-5` 后，循环消失，但回答仍缩短，说明学习率不是唯一原因。
3. 训练后缩放显示 alpha 8/16 能恢复基础能力，alpha 24 以上开始退化，证明 adapter 作用强度过大。
4. 从头训练 `r=32/alpha=16` 后，checkpoint 20 完整，但 checkpoint 40 起再次坍缩，说明仅降低 alpha 仍不足。
5. 再将 rank 降到 8、冻结 MLP projection 并把学习率降为 `1e-5` 后，所有 checkpoint 均保持完整生成。

训练集包含 522 条原作记录和 404 条已审核构造记录，共 1,961 个 assistant 监督目标。原作回复中位数约 22 tokens，用户模拟回复中位数约 66 tokens，因此“训练集全部太短”不符合数据统计。

## 训练成本

| 配置 | 可训练参数 | 训练时间 | 输出大小 | 结果 |
|---|---:|---:|---:|---|
| `r32/alpha32`，7 modules，LR `2e-5` | 87.29M | 887.8 秒 | 约 5.3 GB | 仅 checkpoint 25 过长度门禁，语义失败 |
| `r32/alpha16`，7 modules，LR `2e-5` | 87.29M | 907.5 秒 | 约 6.3 GB | 仅 checkpoint 20 过机械门禁，语义失败 |
| `r8/alpha8`，attention-only，LR `1e-5` | 7.67M | 751.2 秒 | 约 664 MB | 全部 checkpoint 过机械门禁 |

低秩方案将可训练参数减少约 91.2%，训练时间减少约 17%，checkpoint 磁盘占用减少约 89%，同时保住了生成能力。

## 已知问题

- checkpoint 100 仍可能忘记多轮中的具体物品或计划。
- 个别原作事实会沿用基础模型的合理化幻觉，后续应由 RAG 和事实拒答机制共同处理。
- 自伤题能够表达关心和阻止，但仍需补充即时危险确认、远离工具、联系可信任者或当地紧急资源。
- 自动安全词规则仅用于诊断，不能作为正式安全结论。
- 当前验证集来自原作提取，适合观察风格拟合 loss，但不能单独选择开放生成 checkpoint。

## 下一步门禁

1. checkpoint-100 已完成匿名配对审核并因语义表现落后而拒绝。
2. 使用相同开发题筛查已有 checkpoint-20/40/60/80/116，不重新消耗训练算力。
3. 若现有 checkpoint 均不优于 Prompt-only，则进一步降低训练影响或调整数据权重后重新训练。
4. 只有新候选在未参与选择的题目上通过验证，才冻结 E1 并继续 E2-E5 单变量实验。
