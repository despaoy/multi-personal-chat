# R1V4 E1 匿名语义审核包

## 审核目的

本审核比较 Prompt-only 与稳定性校准训练所得候选 checkpoint，但在审核完成前隐藏二者身份。它回答的不是“模型能不能正常生成”，而是“LoRA 是否真的改善了月社妃的人物表现，并且没有带来更严重的事实、多轮或安全问题”。

当前状态为 `ai_assisted_review_pending_human_confirmation`。用户已独立填写前 6 题总体选择，随后由 AI 在不揭盲的情况下补充五维评分、理由及其余 24 题初审。E2 继续暂停，checkpoint 100 仍只是候选，不是正式 E1。

## 文件说明

- `BLIND_REVIEW.md`：当前审核主文件，包含用户选择和待确认的 AI 辅助初审。
- `blind_review.json`：原始结构化空白底稿。在用户确认前不回写，避免把 AI 意见误记为独立人工结论。
- `blind_key.json`：答案映射表。完成人工审核并锁定决定前不要打开。

## 题目组成

共 30 条开发题，全部来自同一次真实评测，`mock=false`：

| 类别 | 数量 |
|---|---:|
| 人物性格 | 8 |
| 安全情景 | 8 |
| 多轮一致性 | 7 |
| 原作事实 | 5 |
| 人物关系知识 | 2 |

7 条多轮题均保留三轮用户问题和两侧的三轮完整回答，没有只截取末轮。

## 审核方法

1. 只打开 `BLIND_REVIEW.md`，不要查看答案表。
2. 逐题检查 AI 初审的选择、分数和理由；同意则保留，不同意直接修改对应内容。
3. 特别复核标记为 `both` 的严重错误，以及事实、多轮和自伤安全题。
4. 确认 30 条后，将该版本锁定为人工最终决定，再同步到结构化结果。
5. 只有决定锁定后才打开 `blind_key.json` 揭盲汇总。

回答更长、语气更华丽或提及更多人物，不代表质量更高。应优先判断是否符合原作依据、是否准确承接问题，以及情景选择是否稳定合理。

## 继续实验的条件

揭盲后只有同时满足以下条件，才能把候选冻结为新的 R1-E1 并继续 E2：

- 候选总体不劣于 Prompt-only，且优势不是由少数单一类别造成。
- 人物一致性和情景决策没有系统性下降。
- 没有新增严重事实错误或多轮遗忘模式。
- 安全题不存在不可接受的严重退化。

若候选未通过，不删除这次结果。应保留为负结果，再根据逐题错误决定调整数据、训练强度或 checkpoint，而不是直接开始 E2。
