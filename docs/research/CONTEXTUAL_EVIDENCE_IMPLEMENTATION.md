# Contextual evidence implementation log

## Goal and execution boundary

Implement and verify context-conditioned memory/evidence selection, with reproducible evaluation and evidence-conditioned training data. Preserve existing uncommitted work. No paid API calls, deployment, credit resets, or long training jobs without explicit authority. Check account usage periodically and stop near 10% remaining. The initial check on 2026-09-19 showed 45% remaining in the weekly Codex window.

## Planned sequence

1. Establish bounded, immutable evidence-selection contracts and strict model-output validation. Keep scope, lifecycle, provenance and prompt-trust boundaries outside model control.
2. Add opt-in contextual memory selection before final top-k truncation, reusing recent conversation and the low-level local inference client. Preserve the baseline and record explicit fallback/selection outcomes.
3. Wire the existing cross-encoder into multiscale RAG; separate semantic scores from heuristic scores, with deterministic fallback and tests. Do not claim normalized logits are calibrated probabilities.
4. Add evidence-conditioned training records and counterfactual/contrastive evaluation utilities, with split-leakage checks and no synthetic results represented as real-model gains.
5. Run focused and broader regressions; document exact commands, outcomes, configuration and remaining real-model evaluation requirements.

## Acceptance criteria

- Model output cannot invent candidate IDs, expand memory scope, rewrite evidence, or become trusted system instructions.
- Irrelevant evidence can be rejected without filling top-k; malformed/unavailable models have bounded, observable recovery.
- Feature-disabled behavior remains compatible with existing tests.
- Semantic ranking is not silently overridden by lexical title bonuses or interpreted using an unrelated score threshold.
- Training/export and evaluation preserve provenance and hold out complete source groups.
- No claim of improved real-model quality without measured comparison.

## Results

Implementation in progress. No production model-quality gains established yet.

### Implemented experimental paths

- `character/evidence_selector.py`: bounded local-model memory decisions over original candidate IDs; no rewriting, all-reject supported; malformed/unavailable/oversized review fails closed. Recent dialogue, persona values and soft state remain untrusted input data.
- Contextual recall reads all **already scope-authorized** visible claims, not only the last 100. Recent user messages inform recall; assistant guesses do not become retrieval facts. Relevance-only modality fusion prevents high importance/recency from crowding out the only matching old claim. The final reviewer sees at most 24 candidates and selects at most 5. Full-scope scanning is a correctness-first experimental path, not a scalable ANN implementation.
- `character/contextual_policy.py`: opt-in persona-conditioned choice of closed strategy IDs. The existing compiler still enforces safety, explicit tasks, boundaries and uncertainty. Relationship progression has NOT been replaced with a learned longitudinal model.
- Multiscale RAG has its own `CHARACTER_RAG_RERANKER_ENABLED=false` gate after the raw-text experiment below regressed; the generic KB switch cannot silently promote it. Semantic scores are not modified by title/lexical bonuses. Score method is attached to each result (not inferred from shared mutable last-request state). Negative logits cannot turn into high confidence through recall-score fallback. The new logit threshold is provisional until independently calibrated.
- `knowledge/multiscale_rag/visibility.py`: an explicit character/scene/continuity boundary filters cards, parent scenes, relationship timelines and raw excerpts. Missing or unapproved annotations fail closed. This is a retrieval API capability; no existing canonical knowledge has been automatically annotated and ordinary chat does not yet supply a boundary.
- `training/evidence_dataset.py` and `scripts/export_evidence_training.py`: reviewed evidence-conditioned SFT and conversational preference export. Uses the production untrusted-evidence wrapper. Gold evidence labels stay out of prompts. Detects cross-split scene/source/text reuse. SFT requires fixed independent validation, no sample-splitting packing and no token truncation. DPO/ORPO entry checks prevent evidence loss through length limits and reject non-train pairs.
