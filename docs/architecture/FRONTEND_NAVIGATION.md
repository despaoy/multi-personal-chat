# 前端导航精简（2026-09-22）

本轮重构共享布局、导航和工作台，不改变业务 API、路由地址或管理员权限。

## 信息结构

- 日常工作默认展开：工作台、角色与记忆、历史记录、知识库。
- 模型与训练：LoRA 管理、训练、意图训练、路由。
- 评测与实验：评估、实验、偏好、假想分支。
- 系统管理：监控、平台连接、Claw、设置。

后三组默认收起；进入组内页面自动展开所属组，仍可手动收起。搜索按名称、翻译、常见别名和路径筛选，无需知道功能在哪组。普通用户仍只看到假想分支，搜索不会绕过权限过滤。

导航定义集中在 `src/lib/navigation.ts`，同时用于侧栏和顶部页面定位。原有 16 个入口全部保留。移除无真实健康数据支撑的“系统运行中”和每秒刷新的“最后检查”，真实状态在运行详情及监控页查看。

首页优先展示四个操作和三项指标；图表与运行详情按需展开，图表组件仅展开后挂载。模型切换统一前往已有 LoRA 管理页，避免首页同时承担配置管理。统计失败不会让快捷入口消失；缺失统计显示横线而非虚构为零。

手机隐藏固定侧栏，改用具备焦点约束、Escape 关闭、关闭后恢复焦点的对话框式导航。点击链接后关闭；窄屏统计采用三列紧凑卡片。提供跳到正文链接、当前页面标记和可访问控件名称。

## 验证

- `npm run ts-check`
- 对改动组件执行 ESLint。
- Node 24：`node --test scripts/test-navigation.mjs`，5 项测试覆盖路由完整性、分组、角色过滤、搜索与子路由。
- 本地启动前端后运行 `scripts/test-navigation-ui.mjs`。需要 Playwright；可通过 `NAV_TEST_PLAYWRIGHT` 指定模块路径，`NAV_TEST_BROWSER` 指定浏览器程序，`NAV_TEST_URL` 指定本地服务。
- 浏览器脚本拦截全部 API 使用测试数据，不登录真实账号，不修改真实数据。9 类检查涵盖桌面、手机、权限、导航以及统计失败；截图输出到系统临时目录供人工检查。

本轮检查了 1440px 桌面与 390px 手机截图。未重写各业务页面内部的复杂表单；这次调整集中解决功能入口过多、页面层级不清的问题。
