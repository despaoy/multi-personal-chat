# A＋B＋C：人物选择、会话连续性与自然节奏

2026-09-22。本轮只改角色聊天后端，不训练 LoRA、不改 RAG、不新增逐轮审核。已有画像在进程内缓存，运行中的后端需要正常重启后才会重新加载新版画像；本轮未操作部署。

## A：人物影响回应选择

人物画像新增作者维护的 `response_preferences`，按顺序填写少量倾向：

- `reflect_content`：注意具体细节，表达自己的观察。
- `acknowledge_emotion`：注意对方的感受。
- `stay_present`：安静听，不急于解决。
- `brief_self_disclosure`：表达有依据的自身看法，不虚构经历。

月社妃配置为前者优先、最后一项次之。其他人物未配置时沿用现有行为。配置不支持任意指令或安全策略，加载时验证。

复用现有策略候选分数，仅在普通对话且候选本来合理时，以人物偏好决定近似选项的顺序：候选至少 0.3，与最优候选差不超过 0.2。不新增好感分或独立打分器。明确任务、拒绝、收尾、争执修复、安全和低置信判断不使用此偏好覆盖。

最终提示使用“更留意具体细节”等软关注提示，而不是新增第一句/第二句脚本。既有明确边界及负面倾诉约束仍有更高优先级。性格并不会在所有情景都改变策略。

## B：临时会话便签

从本轮已有历史最多 24 条中提取一个小便签，无额外数据库查询或模型调用，不持久化、不跨用户缓存：

- 最近两条用户话题引文。
- 一条较早的事项线索（计划、面试、考试等）。
- 最近六条用户发言中的明确纠正和交流意愿。

每项原文最多 180 字符，仅放入不可信参考区，不能作为新长期事实或系统指令。角色自己的发言不会被当成用户事实。本轮消息优先；显式转题切断此前线索，识别到完成表达后不再提升旧事项为待续线索。相对时间不解释成当前日程。

这不是语义总结器，也没有证明某项计划仍未完成。只覆盖现有历史窗口，关键词识别可能漏掉含蓄转题或完成表述；原始历史仍保留，便签只是强调相关线索。更长跨度的连续性仍由现有历史/记忆机制承担。

## C：表达长短与重复节奏

月社妃画像不再要求日常固定一至三句、先判断再补理由。普通聊天允许短反馈，也允许必要时展开。

查看最近三条助手回复：开头前六个去标点字符重复时给一个避免套路开头的提示；最近两条均以问号结束时提醒无须为了延续聊天再提问。它不是禁止提问，更不会调用模型审核、重写或随机制造错字。安全与明确任务场景不加这类节奏提示。

## 验证与试聊

新增 20 项测试，覆盖人物差异确实进入最终提示、明确任务不被覆盖、转题/完成/纠正、历史上限、不可信数据隔离、重复提示以及服务无需新读写。相关回归两组共 355 项通过；仍有依赖弃用警告。

可用以下短对话检查真实体验：

1. 说“明天要面试”，聊几句吃饭，再说“还是有点怕”：应结合面试线索，但不擅自确定原因。
2. 接着说“换个话题，聊音乐吧”：不应继续追问面试。
3. 说“不是这个意思，我是想换项目，不是辞职”：后续不再按辞职讨论。
4. 连续几轮分享日常：不应每轮都以“听起来……”或问题结尾。
5. 明确要求详细解释：不应被人物的简短倾向压缩成敷衍回复。
6. 在类似普通分享场景对比两个配置不同倾向的人物：关注点应有所区别，但不能为展示差异而违背事实或用户意愿。

未运行真实模型的成组对照或盲评，自动测试通过不代表自然度已有量化提升。后续应使用相同多轮输入做前后盲评，分别观察人物一致性、承接、模板感、任务完整性和边界尊重。
