# 阶段167：普通公共来源在最终发送边界重核对

日期：2026-10-05。整体优化目标active，单项达到可用标准后转向下一实际薄弱点，公网开放暂不考虑。

## 原生失败及根因

普通公共来源在检索阶段新鲜读取正文后，经过异步对象、方面和来源事实审核，最终生成没有再核对数据库中的该份资料。使用上一阶段已保存的完整虚构两文档、问题及实际审核响应，对真实正常SQLite数据库和向量索引一致复制；在正常事实审核请求已经准备、响应尚未返回的明确隔离故障点，通过正常delete_knowledge_document删除第二份来源和分块并在同事务使索引变脏。完整初始问题含当前适用范围、通常材料、全部豁免条件、条件不全情形、否定及末尾例外，未发布年度应未知。资料删除后不应继续引用旧内容，不是测试缺少信息或模型规模原因。

实际MiniLM CPU、FAISS/BM25、正常索引校验及内部_generate_reply_impl走当前模型管理器和官方DeepSeek Flash提供商。五份以前实际成功审核只有整个模型payload相等才离线精确复用，原响应和授权不改；主最低层使用明确零云消息观察器，仅返回占位文字，不宣称真实语义回答、认证、HTTP或历史交付成功。基线进程终止后确认：删除的整份正文仍进入主模型消息，六项事实仍有删除来源的接纳引用；独立来源与完整问题正常。

## 服务器根因修复

在正常检索fresh知识文档读取时，给实际有检索成员的来源留下内部source_authority_snapshot，哈希覆盖id、标题、正文、类别和知识库ID，不保存额外正文，也不把内部哈希或回调放入模型消息和完成快照。可选全文受预算排除或不可用时仍保留来源版本核对。来源数据库绑定到同一全局正常检索reader，不能借调用方不同数据库同编号恢复来源。

共享生成请求增加可信public_context_revalidator。在初始编译、实际主发送前及守卫重试前异步重读选中来源；逐份验证完整快照，删除、正文和范围变更或单来源读失败均撤下该来源，其他独立来源继续核对。撤下其分块和完整原文，递归撤下依赖注册/引用片段的背景证据，重新按剩余包生成证据；清理对应文档、引用及来源摘录。失效的指定来源查找改为not_resolved，不谎称全局查无。原事实/身份/对象审核回执原样留在内部，通过正常最终可见片段再次结算，不伪造许可或已审核事实；别名和多项事实的来源证据必须实际仍可见。全部公共包失效时保持正常不确定表达，独立私人上下文不删除。

主模型进行期间如公共来源失效，最终计划重新结算，旧引用不返回，不把旧回答及正文再次发给引用补全。补全返回后再次检查公共来源，失效引用同样不接纳。已送出的主模型输入不能追回；本阶段验证的是发送前和后续引用的可观察核对边界，未宣称数据库检查与网络发送是跨系统原子事务。回调仅内部请求使用，不改变已保存完成快照。未新增模型调用或业务存储修改。

## 针对性测试及实际复验

12个新增节点使用正常持久化SQLite、完整独立虚构规程和问题，验证删除、正文、标题、类别和知识库范围变更、单来源读失败、无变化和无关元数据不误撤、依赖登记和后代背景递归撤销、所有公共来源失效仍保留正常捕获私人原话、初次编译之后发送前改变、守卫首次回答后改变及引用补全不得重发失效资料。模型响应均明示零云单元桩，没有伪造真实DeepSeek答案或审核许可。加两个直接受共享回调变化影响的私人来源重试/完成快照节点，共14唯一节点全部通过；不重复旧全量或已通过付费主答。五个变更代码和测试静态0，只格式化新文件，旧文件保留既有格式。

只重跑失败原生链路一次：同完整问题、同真实初始数据库和索引复制、同五份实际响应完整输入相等的离线复用，仍在同一点执行正常删除。最终被删全文不再进入模型输入，删除来源接纳事实由六项降到零；独立完整原文和原问题仍可见，正常API partial_answer/abstained保留。7/7链路完整性检查通过，没有新付费主答语义验收，也没有将旧正确主答冒充新答案。
