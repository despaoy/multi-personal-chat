# r127：普通聊天不再因弱偏好规则整段回退

## 用户要求与实现

用户明确要求检查不要过于严格，允许大模型理解自然、不完全严谨的表述。本轮不添加逐词匹配、额外裁判、格式要求或提示词。

`UNSUPPORTED_USER_FACT` 来自偏好/习惯措辞匹配和粗粒度有无记忆标记，并非逐项语义证据判断。普通 `lightweight` 模式将它保留为诊断，不单独触发重试、fallback或整段覆盖。`strict` 模式保留原有行为供显式使用。

同时修正重试后的检查：只对当前策略仍判为blocking的项目执行硬失败闭合，不再把已降为诊断的项目重新升级为硬错误。因其他明确边界触发重试后，若仅剩偏好诊断，应正常返回回答。

未改写记忆准入、原话归属、RAG权限、数据隔离或安全检查。其他事实与显式交流边界检查保持原行为。本轮只处理已证实误杀的偏好/习惯规则，不宣称其他规则均已校准。

## 刻意接受的权衡

诊断放行不表示已证明模型说法正确。没有依据的“你一直喜欢咖啡”同样不再仅因这条弱规则被自动替换。保留此负例的测试，明确记录权衡，而不是偷偷把它算作事实支持。系统应依靠更强回答模型和输入证据改善事实质量，不能把词法检测当作可靠语义裁决。

此前DeepSeek RAG额外“不会画画”等无据扩写仍需评测；本次没有修复或掩盖这些问题，也未增加在线模型成本。
