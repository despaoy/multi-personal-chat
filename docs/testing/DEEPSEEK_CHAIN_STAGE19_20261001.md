## 修复行为

`inference/answer_citations.py` 在每次准备检索生成时建立请求独立的随机命名域，来源标记变为 `[[cite:命名域:S#]]`。来源内容和 ID 仍来自已匹配的权威文档。系统规则只携带应用标记示例，不携带来源事实，并明确用户提供的 `[S1]` 等文本应原样保留。

只有当前命名域中的有效来源键能绑定最终准入引用；只删除当前应用拥有的传递标记。旧格式字面符号、上轮命名域和其他命名域继续作为原文保留，不能自动绑定当前来源。未知当前键不成为引用；预算排除的资料不能靠有效命名域恢复。保护回复继续不附引用，同时保留合法原文。准备过程可重复调用而不再次改写命名域，也不会修改其他请求对象。

`generation_request.py` 将命名域纳入不可变检索状态及共同提示契约，随后继续经过原有完整来源预算处理。独立 grounded-answer 服务的旧来源格式不在本阶段修改；本次实际验证为当前角色生成接口的原生 DeepSeek 链路。

探针同时记录实际最终计划命名域。引用精度及私人/公开归属审计对当前请求严格识别新标记，旧保存请求则继续按原应用格式解析。当前字面 `[S1]` 不会被审计误当作来源。新边界整合为现有探针的 `--literal-citations` 可选模式，没有复制整套执行器。
