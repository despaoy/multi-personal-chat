# 阶段124：来源依赖协议与上下文主体审核

本阶段实现三个实际链路改造：完整请求按原始句段编号分类为私人记忆、当前输入、公共知识、输出控制或来源未解析；私人依赖得到确认时跳过无关公共检索；只读写入授权独立于查询关键词；上下文召回不再让含糊指代的词面主体判定直接否决整轮记忆。

来源规划保留完整原始问题和全部原始句段。模型只返回来源依赖编号及已有原文检索词，不生成事实、不授权写入。严格校验编号类型、范围、各组内重复、完整覆盖与额外字段；同一完整句段可以同时包含内容和输出要求，所以跨组多标签有效。旧版仅检索词输出不能据此认定私人任务；来源未解析仍走保守原路径。字段值未知不等于不知道应查哪种来源。规划提示使用独立虚构资料解释两种未知，没有把实际测试答案写入提示。较短任务及旧明确来源路径保持，不额外重复付费规划。

初次私人原生任务5次调用、HTTP200，内容17/17、完整性13/13；规划已覆盖全部15段，但最初的互斥组协议误拒绝内容与控制重叠，仍进行了公共检索。保留原回执，以同一实际规划输出免费证明多标签修复，不重发已正确主回答。

新缺失主体任务初次免费预检因缺少完整已知私人来源对照而失败，零模型调用；未放松完整信息门控，改用完整已知对照和确实未记录主体并列任务。实际5次调用，原生200、内容27/27，初始完整性15/17：规划误把未知字段当成未解析来源，导致多余公共检索。只复测失败规划器两次，每次一个辅助请求，不重发已通过主回答。来源类别与字段值区分、独立提示示例修改后，实际失败输入规划为纯私人依赖、公共与未解析来源均为零。首次低层辅助工具在端点校验时停止，未发出付费请求；配置模块误生成的环境字段立即按完整原始文件哈希恢复，正常服务配置与密钥均保持原样。

新完整混合任务实际5次调用、原生200，完整性17/17：完整私人原话与新的完整虚构公共规程都出现在同一已付费主请求；公共真实导入和检索成功，旧八条记录所有字段及旧来源不变，没有写入器调用或记忆变更。初次严格输出审计12/19，保留失败：模型将部分布尔值和理由嵌套在子任务对象中，未完全遵守要求的顶层格式。按实际结构逐项核对内容20/20，所有未知审核、两类来源不能互相担保、材料不可免除等含义正确。此免费内容核对不撤销格式偏差，不重发通过的答案，不把格式差异当作资料未送达。

随后新完整私人请求原生500，在主模型之前被完整来源门控阻止，已付费三个辅助请求均记账。真实召回读取八条记录、取得八对精确授权来源回执，却全部过滤。逐条免费诊断表明时间、字段、生命周期和当前纠正检查均无问题：解释句中的中性代词被最近代词启发式当成非用户主体，整轮私人偏好全部被否决。

因此改造召回与使用的职责：无语义审核的旧路径继续保留主体抑制；上下文路径只有整条原始请求的所有子句均为闭合第三方/角色查询时才提前按主体排除。含糊指代、混合主体、引用和未知结构都交给已有必经语义选择器，原始完整请求与授权候选逐条审核；召回候选不等于已确认事实或已注入。选择器拒绝主体、输出不合法或失败时，候选不进入回答。授权来源、撤回删除、低置信度和生命周期检查保持。

修复后只续测主请求尚未发出的失败任务，使用同一844字完整问题和同一真实种子，不伪造记录或更改来源计数。新请求5次调用，原生200，链路19/19、内容19/19：八条记忆自然进入召回及逐条审核，实际需要的完整来源与全部八限定进入主模型；私人依赖无公共检索、无公共弃答、无写入器或记忆变更。声明确定性不能证明现实审核、实际饮用或当前位置；各限定仍须累积保留。原失败回执与三个辅助费用完整保留。

仅运行新协议和直接受影响测试：初始43次通过、多标签修复2次、来源未知修复5次、主体架构16次，共66次通过执行，包含直接受影响节点的再次执行，不宣称66个唯一用例。静态检查无新增诊断，原有一项保持。新文件格式化前后语法树一致，未格式化旧实现。没有重测旧全量测试，也没有重发已通过的声明写入、历史推进或主回答。

本阶段25次实际云HTTP200，四次主请求、21次辅助请求；四次原生成功、一次主模型前原生失败。主模型官方Flash、非思考、2048输出；审核输出保持768，完整来源不裁剪，正常历史不清空。按保存usage/cache既有口径估算0.31750472元，不是平台账单或当前官方报价。两个失败规划器调用、被阻止主请求的三个辅助调用均包含在内。免费预检、诊断与审计不计模型调用。所有任务已终止。

服务器先修改并验证，随后只重启后端加载已测试源码，服务就绪200；原提供者配置、环境文件及其他四项服务进程保持。测试资料、真实记录身份、来源原文和实际回答留在服务器，仓库只同步实现、独立虚构单测和安全报告。整体目标继续，不据这几类任务宣称所有长期记忆/RAG场景已无误。下一阶段可验证混合任务公共依据不足时的分任务状态，以及输出格式契约；按失败维度开展新完整用例，不重复已通过付费主回答。
