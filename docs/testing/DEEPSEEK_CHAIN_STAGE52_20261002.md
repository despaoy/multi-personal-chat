根因与修复

PostgreSQL 的同步适配器和异步迭代器原来每一页分别查询，读已提交隔离会看见不同版本。SQLite 同样缺少覆盖整个分页扫描的事务。索引重建已有修订号 CAS，会拒绝重建过程中的旧结果；但关键词回退没有该最终提交校验，直接向调用方返回跨页组合。

PostgreSQL 现在让所有页共享一个 REPEATABLE READ、READ ONLY 事务。同步适配器桥接整批数据，内存仍受一个页大小约束，避免逐条跨事件循环。异步迭代结束或显式提前关闭会释放事务；同步适配器关闭时也关闭仍停在 yield 处的读生成器。SQLite 使用独立连接、query_only 和覆盖整个扫描的事务，不影响原线程连接正在做的写操作。原有重建修订号校验继续负责拒绝并发更新后的旧构建结果。
