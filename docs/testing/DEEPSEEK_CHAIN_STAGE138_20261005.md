# 阶段138：角色任务的原文位置、叙事范围与最终证据接纳

整体优化继续进行，公网开放不在范围。本阶段角色证据覆盖达到可用标准；没有要求每个模型输出格式都100%正确，也没有把本阶段验收作为整体目标完成。

此前完整混合请求已召回角色原作片段，业务与私人内容正确，但角色关系、引用及出处为空。根因是通用业务的未知状态与角色来源混在一起，角色片段缺少独立任务证据及叙事范围回执；人物自述不能证明无条件客观关系，也不应因此丢掉可引用的有限叙事内容。

角色检索现在读取所有实际已选候选对应的可见原作声明行段，使用原生证据与父记录编号、完整索引声明、原始引用范围、原文哈希和实际提取配置。索引声明及元数据仍未独立核验，行段完整不等于整部原作完整。缺失或不可见来源不能变成可用证据。文件读取前后核对同一快照，审核及最终接纳时重新核验；完整行段及原问题不为预算裁剪，容量超限明确保留失败，不发送缩水请求。

独立角色审核读取完整共同问题、原始实际对象绑定、任务及全部新鲜原作。全文逐行生成实际位置目录，长行分成连续位置但正文完整保留。模型只选择原文位置和任务对象，不能生成引用或出处；后端从原文位置生成逐字引用与出处。审核区分直接陈述、人物观点归属、有限情境与无支持，不能把人物自述升级为客观关系；有限已知内容与未支持部分同时保留。语义范围属于模型判断，程序逐字验证不构成事实真值证明。

一次实际审核初始返回了有效的两项角色引用，另给原绑定的其他两项任务返回空证据。原校验仅按角色任务总数拒绝整份结果，导致有效证据丢失。现逐项验证实际绑定和来源范围：必须覆盖全部角色任务，不允许缺失、重复、未知编号、跨对象引用或额外字段；其他已绑定任务只有明确无支持且空证据时可以忽略，其状态和限制不进入事实回执，不能证明它们自己的资料。完整实际原始响应保留，忽略数可重新验证。未知或跨范围有证据结果仍拒绝。用原同一次真实响应和逐字相同完整输入离线重校验通过，新增云调用0；原失败没有删除或改写，后续解析失败也保存实际raw。

角色回执适用于混合与纯角色入口，业务事实审核保持独立。最终生成请求核对完整消息绑定、实际原始审核、目录及全部入包字段。只有真正接纳了完全一致的原文证据包，引用、出处及限制才进入覆盖元数据；相同引文的业务编号或被改写包不能冒充角色来源。没有入包不能经metadata泄漏引文。原作变化时移除它和依赖的旧证据包，保留无关业务来源，角色相关内容转为未知，不能借旧索引或私人偏好补齐。

38个唯一新增或直接相关测试节点通过（33新、5相关），覆盖完整别名映射、叙事否定、未知不等于否定、混合与纯角色入口、跨范围空结果及越权结果、原文变化、最终预算未接纳、原始响应篡改、容量和取消。只测试新增、失败或直接修改部分；没有旧全量，也没有重复已通过主答。新文件格式化前后AST一致，旧文件仅窄范围修改；新增静态诊断0。

原完整混合用例保持8条真实保存记录、47个正常历史回合、完整1098条角色索引和全部原作。通过正常认证API、隔离PG、原生规划器及正常授权资料导入，唯一一次真实主答保留私人8限定、业务5字段及否定和末尾例外；全部20项链路核对通过，未写记忆、未触发护栏重试或回退，未人工替换历史、身份、分类、任务、来源状态或最终回答。

主回答新增角色关系说明，并返回三条逐字引用及三处出处列表，三对均与实际接纳的后端原文位置完全对应。原验收期待单字符串，所以原型检查18/20保留；对实际列表逐项核对后内容与引用20/20。原始回答仍带围栏，严格裸JSON未通过；没有把列表改成字符串或把围栏删掉伪造原始成功，也没有为格式重复付费。独立单次语义审核保留完整原问题、实际主答消息、角色审核及全部来源，判断关系未超出原作、叙事归属、未知边界、否定和引用出处五项通过，无未支持声明；这是模型审核意见，不是程序证明客观关系为真。
