# 阶段148：结构化记忆的当前存储版本核验

日期：2026-10-05。整体目标 active，公网开放不在范围内。

## 根因与最终行为

正常 SQLite 来源捕获、规则提取、规则写入和作用域内召回产生真实结构化记忆，没有在测试中人工构造 MemoryItem 或授权。关闭原话召回的合法结构化路径中，未删除正向控制通过；实际按编号删除并确认当前记录不存在后，最终共享生成输入仍包含旧证据，新增反向控制失败。原话核验回调此前只检查有原话包的上下文，结构化投影跳过了检查。

正常召回现在在原始作用域记录读取后、语义及时间投影前，记录所选记忆的内部存储版本；涉及一跳事件证据及实际读取的来源回执时一并绑定对应版本。模型看到的合法投影无需与数据库摘要文字相等。每次主答及守卫重试前核对当前作用域记录及绑定回执，删除、证据、生命周期、有效时间、限定元数据或被读取的来源变化都不能沿用旧包，也不能替换成未经本轮审核的新内容。

独立记忆及公共证据保留，失效包、相关备份与复制历史清除；冻结完成快照、选择审核和最终模型消息不带内部版本。版本字段不参与 MemoryItem 公开内容比较。核验只读数据库，不增加模型调用或写业务数据。缺少内部存储绑定的旧组件包不能据其旧编号获得当前权限。正常历史版本没有变更时仍保留；本阶段尚未验证等待期间仅由时钟推进导致的有效期跨越。

## 针对性验证

16 个唯一节点通过：13 新增、3 直接相关原话核验节点。覆盖删除、独立包与公共证据、状态/限定/有效时间/证据变更、单包读取失败、合法历史版本、合法语义投影、存储记录未变而已读取的来源发生变化、守卫重试及内部版本不进入模型或完成快照。投影兼容用例在真实规则存储记录上明确设置虚构语义元数据与摘要，模拟持久化投影输入；不冒充真实模型记忆写入。所有来源、规则写入和召回实际执行，模型为明确组件 spy。新文件静态零问题，旧文件原诊断基线保持且不全文件格式化。

一次新真实 deepseek-flash 主回答使用隔离 PostgreSQL 正常来源捕获、规则写入、召回和选中记忆物理删除，通过实际共享 API 生成路径。公共规划、分类和审核故障明确为组件控制，未验收原生登录、历史或向量检索。最终输入中删除证据消失，独立完整表述与证据句保留；8/8 内容检查及严格 JSON 通过，缺少公共规则保持未知，部分回答状态正确。源问题和原始模型输入输出只在服务器保存。

新增发送 1，HTTP200 1，主答 1，辅助 0，原生请求 0。usage 估算费用 0.002044 元，并非账户账单。未重测旧全量，未重复已通过付费主答。
