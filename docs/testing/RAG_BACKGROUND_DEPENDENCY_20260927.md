# r133：证据裁剪后的背景依赖

## 可复现机制问题

检索先准备证据与父场景，再按字符预算装入。旧判断只要求任意证据入选，因此 B 证据超长被剔除时，B 的场景摘要仍可借 A 证据入选。最终 token 预算编排也只检查是否有任意证据，同样可产生孤立背景。

新增两个独立测试在修改前均失败。该问题不是模型参数或提示词问题，而是裁剪后未维护依赖。

## 修复

检索输出每个背景的 supporting_document_ids；字符预算与最终生成预算分别检查至少有一个所属证据仍被保留。共享场景允许由任意一个已保留的所属证据支持。引用仍仅来自实际证据，背景不会新增引用。兼容未携带依赖的旧格式，但旧格式仍只具备原有弱保证。

不增加 LLM 调用、不改变人物提示词、不引入案例实体名单。9 项证据包/生成预算测试通过（包含共享场景先剔除首条证据、仍由后续证据支持的正例），定向 Ruff 通过。扩大回归结果另记优化台账。

本轮未做新真实模型评测，因此仅证明入模内容依赖修正，不宣称人物回答质量提高。检索结果是否真正回答问题、错误的 ok/abstention、混合个人/人物问题路由仍待独立处理。

扩大回归：2139通过、2失败、1991未选，.tmp/r133-wide.xml。失败为规则记忆并发晚到的时间冲突未处理，以及PPO初始化reference权重检查；具体追踪见优化台账。不能将这次运行称为全绿，也不能据此断言失败与所有现有修改无关。
