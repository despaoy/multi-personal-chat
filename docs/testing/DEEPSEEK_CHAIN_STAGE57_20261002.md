## 根因与完整合成用例

实际云端服务使用 65536 token 工作窗口，原始来源编译配额为 16384 字符；2400 字符仅是直接构造服务时的默认值，不能误认为实际生产配置。澄溪完整备忘录有 25537 字符，开头明确是未授权初稿，包含联网下载、云端调用、训练/微调和验证集调参候选；150 条完整、无项目授权的合成库存核验记录之后，末尾明确确认最终限制覆盖全部初稿。

末尾提供所有执行条件：RTX 3060 / 12GB，全程离线，禁止下载、云端调用、训练和微调；已缓存且可离线启动的 Mini 0.6B、完整权重/分词器/全部依赖；1800 条三类标注本地文本，固定 1440/360 划分，验证集不得调参或改动划分。验收仅复现推理、记录显存峰值及验证准确率并保留日志。项目、硬件、模型和数据均为虚构测试条件，没有实际运行硬件或本地模型。

已保存历史只说明讨论澄溪并遵守末尾确认限制；新请求要求三天验收清单，明确判断联网、微调和验证集调参是否允许。没有类型化声明或缓存事实。SQLite 的同一完整来源被检索及授权读取，但被 16384 字符配额整体丢弃。将该全文放入同一实际生成编译合同，保守估算连同输出及安全余量约需 10440 token，仍有约 55096 token 未用。因此确认存在过早配额排除，而非资源缺失或模型容量不足。

## 服务器先修复

云端工厂启用完整来源预算延后审核。来源服务按原逻辑查询、排序，并重新核验选中来源的当前授权；若原字符配额整体省略，则把全部完整来源包作为临时候选保留。候选既不是缓存事实，也不是已注入输入。默认本地服务的配额及行为保留。

最终生成编译器校验候选的原始话语格式、来源身份唯一性、完整文本、带时区收据以及未解析主体/当前有效性标签；使用当前问题、角色规则、已有有效记忆、输出预算及安全余量判断整包是否能容纳。能容纳则完整放行，装不下则整包省略，并保留未知状态，绝不截去末尾条件或把未取得原话当作用户没说过。候选审核一次完成，再给公共 RAG 包使用剩余预算；公共包尝试不能改变私有原始来源的这个决定。无额外数据库读取或模型调用。

生成计划保留最终采用的角色上下文，生成前后判断均使用该上下文，避免模型输入已经有原文而后续逻辑仍使用早期省略状态。独立有效记忆不会因长来源超预算被抹掉。原话仍为主体及当前有效性未解析的历史话语，不写成当前事实。

真实 DeepSeek v4 pro 请求采用 65536 窗口，实际模型请求包含完整原始身份及全部正文，末尾没有被截断；来源继续是不可信原话，没有成为系统规则或已确认当前事实。唯一回答给出三天验收，明确不能联网、不能微调/训练、不能用验证集调参，并正确使用 3060/12GB、已缓存 0.6B 及 1800/1440/360 三类数据划分。4 次实际链路调用均 HTTP 200 / stop，后台队列清空，任务正常结束。

## 未验证边界

共享 token 估算并非精确 tokenizer 计数，实际边界压力还需新场景验证。该恢复只处理云端早期来源配额整体省略；已放行来源与其他无包结构的旧证据同时挤满窗口时，仍可能触发既有明确预算拒绝。四个来源锚点、索引排序及历史加载依然有界，无法保证多项目或所有语义问题。候选全文增加暂存和编译成本，尚未测吞吐量。授权重查后的并发删除/修改、跨批快照及所有表达的语义正确性均未获得全面保证。
