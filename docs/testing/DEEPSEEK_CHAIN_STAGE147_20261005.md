# 阶段147：生成前核验私人原话的当前权限与内容

日期：2026-10-05。整体目标 active，公网开放不在范围内。

## 根因与修复

正常隔离 SQLite 捕获和读取完整虚构原话后，公共对象审核的异步等待期间执行真实授权删除。修改前，正向控制通过，删除控制失败：来源表已经为空，最终生成输入仍携带旧的完整原话。断言放在提供者调用之外，同时确认没有 generationError；错误模拟与旧测试记录保留，不能据此声称真实 DeepSeek 审核失败。

生成请求现在持有内部核验回调，以应用准备阶段的角色和所有者范围，在生成入口、主回答发送前及守卫重试前，重新从实际存储读取选中原话。来源编号、完整正文及观察时间必须一致；删除、变化或读取失败时不沿用缓存，也不替换成未经审核的新内容。保留仍有权限的独立整份原话和公共证据。清除已失效的延后候选、备份、原话审核结果、复制历史以及相应记忆投影，防止预算恢复或重试再次带回旧资料。

回调属于内部请求，不进入冻结完成快照或公共返回。核验只读取存储，不增加模型调用，不修改业务记忆。它验证每次发送前的当前状态，不声称可以撤回此前已经发送的内容；本阶段也没有验收不带原话包的独立结构化记忆路径。

## 针对性检查

13 个唯一节点通过，其中 11 个新增、2 个直接相关。涵盖真实捕获与删除、独立来源、正文与观察时间变更、读取失败、同编号其他所有者、延后候选恢复、复制历史、守卫第二次调用前删除，以及冻结快照字段兼容。新增文件静态检查零问题，旧文件保留原静态诊断基线且未全文件格式化。不重跑旧全量或已通过付费主答。

一次真实 deepseek-flash 新主回答使用隔离 PostgreSQL 正常捕获、召回和按编号删除完整虚构原话，实际共享生成入口发送。公共规划、分类与审核失败明确为组件控制，不冒充原生登录、向量检索或真实模型审核故障。最终输入中删除原话消失，独立原话完整保留，14/14 检查通过，严格 JSON 通过，部分回答状态正确。完整问题和模型原始输入输出只留服务器。

首次验证在导入 PostgreSQL 模块时缺少隔离地址而终止，模型请求为零；按同一 PID 和出生标记确认终止后修复验证环境，保留原记录。正式验证新增发送 1、HTTP200 为 1、主答 1、辅助 0、原生请求 0。按 usage 估算费用 0.002085 元，并非账单。
