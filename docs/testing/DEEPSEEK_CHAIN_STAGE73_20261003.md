## 完整用例

三轮原始本人发言，均通过普通用户鉴权的正常聊天入口，实际模型后台提案后落库，后一轮前flush同一任务：

1. 请记住，我喜欢桂花乌龙茶。
2. 请记住，我不喜欢高糖可可饮料。
3. 请记住，我喜欢低咖啡因咖啡，但我只有吃过早餐且当天没有胃痛才喝低咖啡因咖啡。

唯一原始查询（修复前后不变）：按我目前明确告诉你的饮料偏好，列出喜欢的两种饮料、不喜欢的一种饮料，并完整说明喝低咖啡因咖啡的必要条件；条件满足也不能推断我一定会喝。

预期包括两种喜欢、一种不喜欢、两个同时必要的条件，以及必要条件不蕴含一定饮用。

原始模型回复保留Markdown的两个行末空格，JSON表示如下，未修改模型输出：

```json
"按你明确告诉我的：\n\n喜欢的两种饮料：桂花乌龙茶、低咖啡因咖啡。  \n不喜欢的一种饮料：高糖可可饮料。\n\n喝低咖啡因咖啡的必要条件：吃过早餐，且当天没有胃痛。  \n即使这两个条件都满足，也不能推断你一定会喝。"
```
