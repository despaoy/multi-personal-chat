The server-first fix cleans retained evidence inside the same existing owner-lock transaction as claim deletion and source revocation. The shared SQL plan finds actual same-owner source links from the real erased rows, never model-selected sibling IDs. It examines surviving claims linked to those sources and computes every projection before any evidence update. SQLite loads the scoped recursive erase set before deletion; PostgreSQL passes real DELETE RETURNING rows and rolls that deletion back if projection fails. Protected-root/descendant guards, source fences and the existing full-source privacy revocation remain authoritative.

Projection removes only exact complete statements from the actual recorded shared source, using the erased claim's source-backed evidence. It rejects partial statements, clipped overlap, ambiguous or unavailable provenance, unsafe quote boundaries, malformed evidence, inseparable full-quote overlap, and erased material copied into a retained assertion or arbitrary metadata. Those conflicts roll back the entire transaction, including any prior projection, target deletion and source/fence changes. Independent normalized sibling facts remain unchanged. Plain authorized erasure also applies the copy cleanup, rather than requiring an optional retention flag.

Surviving quoted evidence becomes separate literal original fragments in original order. It is never concatenated into a fabricated complete source or promoted to an independently resolved event fact. Its display text explicitly says that only retained fragments remain. The server records fragment offsets and the actual original source-message identity, with complete_original_source=false; it stores no removed text, new invented receipt clock or reconstructed raw-source body. Existing course identity, status, timestamps, qualifiers, attribution and unresolved subject semantics are preserved. The independent verifier checks all preserved fields and metadata against the actual before-ACK row, and checks each exact fragment/offset against the actual complete original source.

Limits and next work: this cleanup uses actual shared-source links and exact independently attributable whole-statement evidence. Tested partial statements, unavailable original speech, retained assertion/metadata copies and malformed or overlapping spans return a transactional conflict rather than false success. Arbitrary semantic overlap remains unproven: a complete erased statement could itself carry a retained course detail, so complete sentence boundaries alone do not prove preservation of every retained fact. This requires a new complete multi-fact statement case and separate provenance review. The fix also does not yet establish erasure of copies in a different older source that is not linked to the erased claim, even though the raw-source owner watermark already blocks earlier raw recall. Same-request semantic proposals that can reintroduce an erased object, clear-all paths and late pre-erasure prepared contexts also need matching evidence-boundary review. Previous hard-crash bookkeeping, historical capacity-probe hooks and Stage24 public-answer omission limitations remain. The continuous memory/RAG/context goal stays active; universal correctness is not claimed.
