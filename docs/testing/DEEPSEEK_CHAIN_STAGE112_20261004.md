# DeepSeek 后端链路阶段 112：保留条件与关系元数据

服务器优先修复了记忆读取后的信息丢失：完整原话虽已传递，筛选候选仍缺少记忆键、版本关系、条件限定、原话观察标记和来源标识。完整主模型参考包也未单独保留记忆键、条件限定和观察标记。现在这些字段随原条目传递，不改写来源、数据库记录、模型决定或回答。

筛选说明区分生命周期与事实有效性：`active` 不证明条件已经成立；观测时间不是事实有效时间；`ADD/COEXIST` 不自动否定较早说明，其他关系标签也不能单独证明具体替代目标、时间或条件。字段仍是不可信数据，不进入系统指令。条件使用键值对列表保留，重复键、最后的例外和全部来源不会因转成字典或前缀截断而消失。预算不足继续拒绝不完整输入。

## 保留的限制

原始回答检查为 26/29，未修改问题、回答或检查器，也未为补标签付费重试。三项未通过结果仍在夹具中：第一项未复述原检查器接受的来源措辞；独立诊断仍识别到来源标题及转述措辞。第二项检查要求确认当前条件真假，而该问题只明确询问未来说明能否确定当前选择或实际结果；回答保留当前选择的不确定性。第三项未按原检查明确表达“非本人真实经历”，诊断没有发现声称本人实际体验的句子，但不能据此宣称该语义要求已通过。

不同条件说明与未来条件、公共例外、未确认实际办理均按原检查通过。服务器端保留完整输入、原始回答和诊断。公开夹具仅包含布尔、计数、费用及已公开的合成公共正文；不包含原生测试原话、查询、回答、私有来源标识或原文哈希。自动审批最初拒绝导出私有来源标识/哈希，改为服务器内核对并仅返回计数；也拒绝一次模型启动，补充核验待测原话全部精确匹配原始合成夹具、隔离测试账号和测试种子后才启动，拒绝本身没有产生云调用。
