# 阶段120：长期记忆限定字段的无损、原子准入

用户授权根据真实链路缺陷进行根本改造。本阶段从完整独立输入发现并修复写入边界的结构问题：模型和原文都有八个限定字段，旧后端只验证前六个；第七项非法键也被跳过。重复规范化键或多项旧式context数组到dict持久化时覆盖前值；JSON同名字段在解码时已经被覆盖。无原文依据的true/false可用在任意限定键上，可能把未观察的条件表示为事实。

服务器先保存原代码，免费完整正例与负例复现；没有把输入缺失或模型能力当作根因。修复为全载荷一次验证，白名单八键全部有机会保存，不允许静默截尾，规范化键唯一，所有JSON层级重复字段明确报格式错误。提示载荷公开实际最大数量、唯一键和禁止截尾契约。自然语言限定仍需原文依据；只有PENDING的certainty=false可由待确认生命周期独立支持，不能据此认证条件成立。单项旧式context数组兼容，多项数组拒绝，避免臆造且/或关系。已保存整条原话的现有捕获路径不因格式错误被改动。

仅运行二十二个新节点、五个直接受影响旧节点，共27/27；没有全量回归、通过后反复重测或旧付费问题重放。去除格式化工具造成的无关改动，清理前后代码语法树一致；新增静态诊断零，原有一项按代码内容保持。新增测试的一项导入排序诊断修复，未扩大测试范围。

一次实际官方DeepSeek Flash写入提取，使用当前生产配置，65536上下文、非思考、实际写入器768输出上限、stop。新的完整中文输入逐字出现在已支付请求中，模型返回一条候选及八个限定字段，新版全部保留且逐字段与独立原文预期一致。同一原始返回在备份旧代码免费离线解析，旧版仅保留六项、丢两项，生命周期ADD一致。未改变回复、强制模型返回数量或重复采样。
