# 阶段144：共享对象解析失败与私人原话部分回答

日期：2026-10-05。整体优化目标 active，阶段通过不是停止条件，公网开放不在范围内。

## 根因与最终行为

完整问题的正向对象解析先通过，六种模拟失败复现了共享 resolve_question_binding 抛出普通异常后丢失实际消息与收到文本。实际生成入口的七个组件控制进一步复现公共失败回执为空。失败现在抛出专门的 QuestionBindingReviewError，携带此次完整输入与真实收到的文本；非文本、超时或传输未收到响应时 raw=None。不修复 JSON、不伪造绑定，取消继续传播，输入容量超限继续在调用前阻止。

生产入口把这类异常转为绑定完整原问题、所有公共义务及独立父段编号的 unavailable 回执。诊断只是内部信息，不进入日志、公共返回字段、后续审核或最终模型输入。成功绑定的原始协议与严格验证保持；诊断中放入合法 JSON 也不能授予绑定，改变诊断输入则拒绝。

新用例在诊断修复后进一步定位：正常 SQLite 捕获和授权读取的完整私人原话已经进入最终模型请求，返回状态却只检查整理后的记忆条目。现在同时检查最终计划中状态 available 且完整出现在实际用户消息里的私人原话，公共缺项仍保持不可用，但回答可标为 partial_answer。不要求原话先伪造成 MemoryItem，也不把偏好或历史自述升级成当前事实。整份私人原话因预算未接纳时仍为 abstention，不能只凭候选存在声称有依据。
