4. 关键洞察

最优候选：E3 (DoRA)
- 门禁 PASS，重复率最低（0.0302）
- 安全率最高（0.5333 > 基线 0.4333），提升 23%
- 输出长度与 E1 基线接近，保持简洁风格
- 元叙事违规为 0，符合角色一致性要求
第二候选：E2 (NEFTune)
- 门禁 PASS，重复率 0.0358
- 安全率 0.5 > 基线，提升 15%
- NEFTune 噪声注入有效提升泛化，效果与 DoRA 接近
不推荐：E4 (RSLoRA)
- 门禁 FAIL，重复率 0.1667 远超上限
- 输出冗长（144KB vs 其他 ~104KB），偏离角色风格
- 安全率退步至 0.3333
- 结论：RSLoRA 在 r=32 下可能导致训练不稳定，输出质量下降
不推荐：E5 (Sequence Packing)
- 门禁 FAIL（诊断性安全率退步）
- 重复率正常（0.0376），长度最短
- 但安全场景表现下降，可能因 packing 改变注意力分布影响安全判断
- 结论：Packing 提升训练效率但不保证效果，需配合安全校准

5. 下一步建议

  1. 盲评优先级：E3 (DoRA) > E2 (NEFTune) > E5 > E4
  2. 正式盲评：先完成 E1 vs E3 的 40 条分层盲评，若 E3 胜出再做 120 条完整盲评
  3. 多种子复现：仅对 E1 和 E3 补充 Seed 43/44 验证稳定性
  4. 负结果记录：E4/E5 的失败是有效负结果，写入研究档案，不删除数据
